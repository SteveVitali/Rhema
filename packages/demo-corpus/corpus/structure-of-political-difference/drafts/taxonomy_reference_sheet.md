# Five Questions Taxonomy — Reference Sheet

## Canonical order

1. Economy — Equality ↔ Markets
2. Coercion — Liberty ↔ Authority
3. Culture — Progress ↔ Tradition
4. Belonging — Universal ↔ Communal
5. System — Insurgent ↔ Institutional

## Profile metadata

- Position: 1–5
- Salience: 0–3
- Confidence: low / medium / high
- Date and jurisdiction
- Object: person / party / government / electorate / document / argument
- Layer: rhetoric / program / practice

## Fifth-axis facets

- Anti-establishment orientation
- Directism versus representation
- Pluralism versus unitarism
- Mode of legitimation: popular will / expertise / law / tradition

## Public families

- **Demsoc** — equality + emancipation
- **Socdem** — equality through institutions
- **Left Populist** — egalitarian insurgency
- **Progressive** — cultural revision + inclusion
- **Green** — ecology + post-material politics
- **Liberal** — rights + pluralism + mixed markets
- **Technocrat** — expert-led reform
- **Christian Democrat** — social market + inherited community
- **Conservative** — markets + order + continuity
- **Libertarian** — markets + personal liberty
- **Welfare Nationalist** — social protection for members
- **Natcon** — nation + tradition + authority
- **Developmentalist** — state capacity + national growth
- **State Socialist** — state economy + concentrated rule

## Recommended syntax

**[optional modifier] + [nearest family]**, followed by the five-coordinate address.

Example:

> Populist natcon — 4 · 5 · 4 · 5 · 1

Use no more than one modifier. When more detail is needed, show the coordinates rather than extending the label.
