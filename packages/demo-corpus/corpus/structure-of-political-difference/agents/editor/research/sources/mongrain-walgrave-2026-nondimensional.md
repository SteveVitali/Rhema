# mongrain-walgrave-2026-nondimensional

- **What it establishes:** Mongrain & Walgrave, EJPR 2026 (online March 30, 2026) — exists as cited in fn 4.
- **Key passages:** 6M+ responses to Belgium's Vote Test VAA across 348 statements vs 13 party leaders: mass opinion shows "minimal, if any, ideological structuring"; elite correlations 2–3× citizens'; four factors explain only 32% of variance; only immigration attitudes cluster meaningfully.
- **Reliability:** Primary (publisher's page).
- **Relevance to this project:** Verifies the draft's "no universal factor structure" use (C8) — but double-edged: it finds mass opinion largely *non*-dimensional, which cuts against any five-axis structure in mass publics too.
