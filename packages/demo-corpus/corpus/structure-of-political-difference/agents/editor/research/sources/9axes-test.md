# 9axes-test

- **URL:** https://9axes.github.io/ · **Accessed:** 2026-07-30 · **For:** v1 review Phase 2
- **What it establishes:** A successor test "building upon the 8values framework" with nine axes: Federal↔Unitary, Democratic↔Authoritarian, Globalist↔Isolationist, Militarist↔Pacifist, Security↔Freedom, Equality↔Markets, Secular↔Religious, Progressive↔Traditional, Assimilationist↔Multiculturalist.
- **Key passages:** "Democratic tends to favour elections and popular opinion, Authoritarian tends to prefer the judgement of the government"; "Federal tends to favour stronger local governments…"
- **Reliability:** Primary source for the test itself; hobbyist.
- **Relevance to this project:** Shows the hobbyist tradition has already explored the draft's "modules": Federal↔Unitary ≈ the draft's centralization tag; Democratic↔Authoritarian ≈ the draft's regime-type tag; Militarist↔Pacifist ≈ the Restraint↔Intervention module; Secular↔Religious ≈ the religion-of-belonging tag. The draft's §X "exclusions" architecture (core five + optional modules) recapitulates, in disciplined form, what axis-proliferating tests did indiscriminately. Also a cautionary example the draft can use: nine undifferentiated axes with no salience or naming discipline is exactly the "coordinate string written in Latin" failure the draft warns against.
