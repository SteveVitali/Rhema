# csa-ai-model-export-controls-2026-06-18
- **URL:** https://labs.cloudsecurityalliance.org/research/csa-research-note-ai-model-export-controls-20260618-csa-styl/ · **Accessed:** 2026-09-16 · **For:** v1 response round, Finding A (instrument; verification rationale)
- **What it establishes:** CSA research note (June 18, 2026). Characterizes the instrument as an EAR "Is Informed" letter, a mechanism "previously applied to semiconductor and equipment exports to China, now asserted for the first time against a commercial AI model's API access." Scope: "suspend all access to its Fable 5 and Mythos 5 models by any foreign national worldwide." Letter not published. Explains the all-user shutdown by "the technical impossibility of performing real-time nationality verification across a distributed user base spanning AWS Bedrock, Google Cloud, Microsoft Foundry, Snowflake, Box, and its own Claude APIs." CAUTION: the note gives the receipt time as "5:21 p.m. ET on June 13", which conflicts with Anthropic's own June 12 statement; treat the CSA date as an error.
- **Key passages:**
  - "previously applied to semiconductor and equipment exports to China, now asserted for the first time against a commercial AI model's API access."
  - "the technical impossibility of performing real-time nationality verification across a distributed user base spanning AWS Bedrock, Google Cloud, Microsoft Foundry, Snowflake, Box, and its own Claude APIs."
  - "a hard global shutoff for all users regardless of nationality."
- **Reliability:** Secondary, industry research note; useful for the verification rationale but contains a date error.
- **Relevance to this project:** Supports the "could not verify nationality in real time" rationale as an analyst's characterization, not Anthropic's words.
