# chen-more-llm-calls
- **URL:** https://arxiv.org/abs/2403.02419 · **Accessed:** 2026-07-30 · **For:** v2→v3; naming the deflationist (Major issue 1)
- **What it establishes:** Chen, Davis, Hanin, Bailis, Stoica, Zaharia, Zou, "Are More LLM Calls All You Need? Towards Scaling Laws of Compound Inference Systems" (NeurIPS 2024 per review; arXiv:2403.02419). Vote/Filter-Vote performance is a non-monotonic function of the number of LLM calls — "can first increase but then decrease as a function of the number of LM calls" — explained by query-difficulty mix ("more LM calls lead to higher performance on 'easy' queries, but lower performance on 'hard' queries"). Compound-system behavior modeled as sampling statistics, no institutional vocabulary needed.
- **Reliability:** primary (arXiv abstract).
- **Relevance:** The named, sharpest form of the deflationary view: multi-agent behavior as predictable sampling statistics. v3 cites it when stating the null hypothesis it must answer.
