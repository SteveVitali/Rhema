## What the structural check found (baseline, prod of `check-build-memory.sh`)

99 violations / 23 warnings. Three disjoint classes:

1. **64× `filename:` violations** — every run-time-insert ticket file
   (`255_R6WATCH.2` … `322_R6FIX.51`) reported "does not match the filename grammar and is not a
   listed chain row". Two upstream parser gaps, not repo defects:
   - `ID_RE` (`[A-Z]+[0-9]*[a-z]?`) admits no second letter run — `R6WATCH.2`, `R6FIX.51`,
     `R6OSS.1` all fail the grammar despite being the repo's standing insert-id convention
     (68+ tickets, all listed in the manifest).
   - The chain scan reads only `## The chain` (manifest L125–479); every insert row lives in a
     table under `## Plan extensions` (L1082+), so `in_chain` fails even where grammar passes
     (e.g. `274_HUMAN__operator-acts.md` → `viol manifest has no row`).
2. **26× `deferrals:` orphan statuses** — status cells with no canonical token. Root cause:
   dated notes appended with a stray `|` separator (not ` — `) inside the status cell, and no
   trailing `|`, so the validator's `$NF` read the appended note instead of the status
   (`'R'` = the first alpha token of `204_R6REC.1`; `'WATCH'` = the first token of
   "watch sweep").
3. **5× duplicate DEFERRALS ids + 1× OPEN-row/GATE-ACCEPT.R7 + wider never-flip class** —
   union-resolve kept both copies of five rows; 31 rows led with `**OPEN**` and carried a
   terminal `**DONE — <date>` note that the first-canonical-token rule (HYGIENE.1) could never
   see; one OPEN row references `GATE-ACCEPT.R7` (a PASSED accepted-deviations readout — the
   checker exempts bare `GATE-ACCEPT` only).

## Repo-side repairs landed

- **Stray-pipe rejoin (26 rows):** each offending row's status cell was split by a stray `|`
   used as a dated-note separator. The fragments were rejoined with the file's own ` — `
   convention and the trailing `|` restored. No text deleted; notes verbatim.
- **Missing canonical token (D-PRB.08-1):** the status cell carried only the appended carrier
   note — `**OPEN — 2026-11-25 (R6FIX.52 / BL-02 normalization):**` prepended, prior text
   preserved verbatim.
- **Duplicate ids (5):** the non-canonical copy's first cell renamed `<id>-dup` with a dated
   normalization note pointing at the retained canonical row — `D-BL38.1-2`, `D-R6OPS.1-1`,
   `D-R6OSS.1-1`, `D-R7DEP.3-1` (the copy that self-declared the other canonical), `D-R7DOC.1-1`.
- **Never-flip class (31 rows):** rows whose final disposition is a dated `**DONE — <date>`
   marker but whose cell leads `**OPEN**` got a `**DONE — 2026-11-25 (R6FIX.52 / BL-02
   normalization):**` header prepended; original cell text preserved verbatim. Rows with
   ambiguous tails (prose `DONE`, re-`OPEN` after `DONE`) were left untouched — D-R7TALK.1a-2,
   D-R7KIT.3b/3d/3e/3f, D-R7COPY.1b, D-R7RO.2-1, D-SPA.16-1/-20, D-SEC.2-1, D-EDIT.1-2,
   D-RES.3-1, D-DEF.1-1 stay honestly OPEN.
- **`docs/adr/README.md`** regenerated via `adr-index.sh docs/adr` — genuinely stale: ADR-126 /
  ADR-128 / ADR-130 still read `Proposed` where their headers now say `Accepted`. (Footgun
  recorded: `adr-index.sh <adr_dir>` writes `<adr_dir>/README.md` — `adr-index.sh .` clobbers the
  repo-root README.)
