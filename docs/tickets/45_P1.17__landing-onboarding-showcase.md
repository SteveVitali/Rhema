   harness's product name never), proof, pricing (the same `pricing.json` as `/pricing`; Essay
   card leads — REQ-POS-2), changelog + FAQ, final CTA + footer.
2. **Drop-zone hero** (REQ-GROWTH-1): a dropped `.md`/`.docx`/`.pdf` or pasted text is held
   client-side (IndexedDB, ≤10 MB), routes to `/signup?intent=review`, and after auth lands in a
   new project with the draft ingested — an 8k-word `.docx` rendered within 20 s with word count
   and detected citation spans (reusing PRB.02's conversion preview + PRB.20's live upload path;
