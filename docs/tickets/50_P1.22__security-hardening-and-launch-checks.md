## In scope — Stage A (code + tests + audits, $0)
1. **The §12.8 verification suite — every control, executable, across the full surface**
   (REQ-SPEC-25; REQ-ARCH-21 amended):
   - **(a) fetcher routing at Full board:** assert a Full-board Editor run's fetch traffic goes
     through the `fetcher` tool (untrusted-document wrapping + per-URL policy apply uniformly);
     Quick/Standard server-tool paths carry the checks below.
   - **(b) untrusted wrapping:** every `fetcher`-supplied page and every chat attachment is
     `<document trust="untrusted">`-wrapped — extend coverage to the surfaces P1.x added (chat
     attachments, figure sources, outline/research fetches).
   - **(c) model-independent verdict source checks:** a `verified`/`contradicted` Tier-1 verdict
     citing a URL that fails the rule (not the claim's own citation, not the reputable-source
     list, not reached from a search result) downgrades to `unverifiable` with
     `sourceCheck: 'suspicious_source'` at commit — plus schema validation of findings, verdicts
     and source notes at commit; re-verify at the new run kinds (Figure, Outline, Research).
   - **(d) outbound-channel limits at the proxy:** >256-char `web_fetch` query strings
     stripped/refused; the per-run distinct-registrable-domain cap; the ≥12-word draft n-gram
     match raising `suspicious_query` → pause + a refusal-class card. Each exercised against a
     planted exfiltration fixture.
   - **(e) the input-scoped second read** never sees fetched pages — a mount-manifest assertion,
     not a review note; subagent outputs are file-read.
   - **(f) privilege separation + the per-run proxy credential** — a shell escape cannot forge
     audit/fetch-log/event rows and cannot spend outside the meter (REQ-SPEC-10/11's live
     posture re-asserted).
   - **REQ-ARCH-32:** an `egress.denied` spike pauses the run — exercised end-to-end through the
     pause signal, not just the proxy unit test.
2. **Tenancy/RLS re-test at full surface** (REQ-ARCH-25/26/27; REQ-DATA-4 amended): every
   tenant-owned table carries `tenant_id` — enumerate, including every table the P1 tickets added
   (notifications, in-app rows, usage read models, preferences, integration tokens, provenance,
   trial entitlements, pricing); `FORCE ROW LEVEL SECURITY` + `SET LOCAL` only; the two-tenant
   pooled-connection test extended to the new routes (Inbox, usage, settings, export-zip).
3. **usercontent-origin + CSP audit:** `usercontent.rhema.tools` (+ `*.usercontent.rhema.tools`)
   serves non-allowlisted types only as `attachment`/`octet-stream`, sets **no Set-Cookie ever**,
   and can never reach session scope; the `__Host-` cookie posture re-asserted (host-only,
   Secure, Path=/, no Domain — a same-named `Domain=` plant rejected); a CSP header audit across
   every web surface with the policy written down; quarantine objects serve only through that
   origin (PRB.20's posture re-checked).
4. **Secrets + posture sweep:** gitleaks clean; provider keys only in `egress-proxy`; Stripe/
   Better-Auth secrets only in Secret Manager; no secret as a plaintext env var to `web`/`collab`;
   the run token + per-run proxy credential file-delivered to the `harness` uid, never env vars
   to the agent process (REQ-SPEC-10); the requirement is re-asserted on the deployed manifests,
   not the design.
5. **Retention + backups audit** (REQ-ARCH-28/29): prod Cloud SQL daily backups (35 retained) +
   7-day PITR per the 2026-09-17 amendment; GCS object versioning; project tombstone → 30-day
   purge → lifecycle delete; account 14-day grace → hard-delete (P1.20's path); the retention
   schedule asserted against lifecycle config — SDK transcripts 30 d, internal events 30 d,
   audit 90 d, usage records + credit ledger 7 y.
6. **The deferred hardening rows:** **D-P0.01-5** — author + review the explicit least-privilege
   IAM policy documents per service (the `link:`-implicit grants made explicit); **D-P0.06-3** —

   **D-P0.01-4** — the self-hosted turbo cache: point `TURBO_API` at the cache backend or re-defer

7. **Launch-surface lint** (REQ-EVAL-19's sweep + REQ-POS-4/5/13): scan every shipped surface —
