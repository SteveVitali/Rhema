## Goal
The client half of the shell: `src/spa` entry mounts TanStack Router (committed `routeTree.gen.ts`, file-based + autoCodeSplitting, every auth'd doc route registered day one per REQ-NAV-1), a root `beforeLoad` owns auth gating, one same-origin `bffFetch` module is the only transport, `GET /bff/session` + `data-spa-boot` hydrate the boot, `SsrHandoff` document-navigates to any route outside the effective flag set, and the client head manager owns title/focus/route-announcement on navs.

## In scope — deliverables
1. `src/spa/main.tsx` + committed `routeTree.gen.ts` — full auth'd route set registered day one; unflipped routes render `SsrHandoff` (document nav → server re-decides; converges in ≤1 boundary cross) (REQ-NAV-1, REQ-FW-4/11, REQ-SEQ-12)
2. Root `beforeLoad` auth gate — 401/no-session → document nav to `/login` (REQ-FW-5, REQ-BND-7)
3. `bffFetch`: same-origin, credentials include, typed JSON, `{error, detail?}` propagation, no automatic POST retries, 401 → session invalidation → `/login` nav (REQ-FW-6, REQ-DAT-2/3, REQ-BFF-30)
4. QueryClient config + route loaders via `ensureQueryData`; `GET /session` endpoint (REQ-BFF-18's pinned path) + `data-spa-boot` read; session as refetchable `['session']` query; `GET /bff/feed-labels` consumer plumbed (REQ-FW-7, REQ-BFF-18/20, REQ-DAT-13 `checkSession` promotion)
5. Client head manager: `docMetaFor`-parity title updates, focus to `<h1>`, live-region route announcements; `scrollRestoration` on + hash anchors focus their target (REQ-BND-8, REQ-UX-7/9, REQ-TST-9, REQ-NAV-7)
6. Settle mechanics: `data-mounted` on the mount node after first paint; `data-renderer="spa"` already on the shell (REQ-VFY-3)
7. 404/routeError pending components + pending-state contract (skeletons, not blank) (REQ-NAV-10, REQ-UX-6)
8. Intent prefetch on primary nav targets (hover/focus → `ensureQueryData` warm) (REQ-UX-2)
9. Copy plumbing: SPA strings resolve to `COPY` leaves / server-built label maps; `@rhema/ui` components stay text-agnostic (REQ-UX-12)
10. Eager-import ban enforced on lazy route leaves — no eager `import()` of a surface outside its own chunk (REQ-TL-9)
