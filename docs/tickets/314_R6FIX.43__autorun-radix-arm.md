## Defect

The 2026-11-23 manual paid-weekly dispatch (operator-authorized; operator measured-DSN path,
`--headroom 3`, `docs/build/reports/2026-11-23_paid-weekly/`) failed four launcher legs
identically — N5, N6, N11, R6 each died 30 s into `locator.check` on
`input[name="autoRun"]`: the locator resolved the element as "visible, enabled, stable" but every
click was intercepted by the `.ide` shell.

Root cause: the run sheet's per-run "This run only — run it to completion" control migrated to
the Radix `Checkbox` primitive (225a_R7KIT.2b — `packages/ui/src/primitives/toggles.tsx`), which
renders `button[role="checkbox"]` plus a hidden `BubbleInput`. The BubbleInput carries
`name="autoRun"` but is `aria-hidden`, `opacity:0`, and shifted off-position — Playwright treats
`opacity:0` as visible, resolves the input, clicks its displaced point, and the `.ide` shell
intercepts. The leg arm pre-dates the Radix migration; the product control works for users (the
styled button is the click target).

## Implementation

`packages/journeys/src/steps.ts`: the four identical inline arms collapse into one shared
`armAutoRun(page)` helper. It still reads the committed `input[name="autoRun"]` for presence and
checked state, but performs the toggle on the *clickable* control —
`label[data-auto-run] button[role="checkbox"]` — falling back to
`label[data-auto-run] input[name="autoRun"]` for the SSR emitter's native input (both hooks are
already declared in `dom-contract.ts`). The closed-`<details>` open fallback is preserved
(`details:has(label[data-auto-run]) > summary`).
