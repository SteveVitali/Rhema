## Goal
On today's IDE geometry, panes never sit un-scrimmed over the draft. The Timeline is closed by default where it would overlay. The overlay and sheet modes get a scrim, Esc and outside-click dismiss, and they never persist their open state. At ≥ 1280 with Files open, the page reflows instead of sliding under the Timeline. The Desk head is never hidden behind the status bar. `paneLayout()` becomes the runtime geometry source. Focus mode always has a visible exit, Esc always leaves it, and it never survives a reload. This is the R7a stopgap: the SplitPane engine that replaces the geometry is 229 R7PANE.1.

## In scope — deliverables
1. **`paneLayout()` wired at runtime.** The controller derives the effective mode and the pane defaults from `paneLayout(viewportWidth, state)` on mount and on resize. The CSS breakpoints stay in parity with it (an existing comment contract), and a test pins the parity. (REQ-PANE-0) [UXC-19]
2. **Viewport-aware defaults.** The Timeline is closed by default below 1280 and in single-pane mode, and opens on demand. The SSR shell default matches, so there is no open-then-close flash. (REQ-PANE-0) [UXC-19, UXC-20, F2]
3. **Overlay and sheet modes** (1024–1279 overlay; < 1024 sheet).
   - They get a scrim plus Esc and outside-click dismiss, with focus returned to the trigger.
   - Their open state is never written to pane storage from overlay mode. A persisted `timelineOpen:true` from a wide session must not auto-open the overlay at a narrow width.
   - (REQ-PANE-0) [UXC-19, UXC-20, F1, F2]
4. **≥ 1280 with Files open.** The page column reflows rather than sliding under the Timeline (the `data-files='open'` overlay arm), within REQ-IDE-9's measure. (REQ-PANE-0) [B1]
5. **The Desk head is never occluded** by the status bar at any reference height, including ~757 px laptop heights. (REQ-PANE-0) [B2]
6. **Focus mode** (REQ-WRITE-4) [B12]:
   - a hover- and keyboard-revealed exit pill ("Exit focus · Esc"), with copy as a COPY leaf;
   - Esc always exits focus, including when no menu is open;
   - `view:"focus"` is session-scoped: never serialized to pane storage and never restored on reload (the codec coerces a stored `focus` to `write`);
   - `?focus=1` still seeds it for the session.
7. **`U3.stopgap` journey body** (registered red by 209; owner R7FIX.1).
   - At 1440×900 (Files open), 1280×800, 1024×768 and 820×1180, it asserts:
     - no open un-scrimmed overlay or sheet intersects the Page text column, the dossier letter column or the finding ticks;
     - the Desk tabs are actionable (`assertActionable`);
     - Esc closes an overlay;
     - focus mode shows the exit pill and Esc leaves it.
   - Exercise the body against a local build where a local target can host it (or through the offline occlusion harness at the four sizes), and record the result in the run record.
   - **Nightly hazard: held `ready-to-flip`.** The nightly runs `main`'s registry against prod, and prod serves pre-R7a code until 224 deploys. A flip in this PR would redden the nightly. So the row stays `expected:"red"`, and the run record marks it `ready-to-flip` with its Stage-A evidence. 224_R7DEP.1, the sanctioned flipper recorded by 209, flips it at the phase preview and prod.
   - `U3.occlusion` stays red for 229.
