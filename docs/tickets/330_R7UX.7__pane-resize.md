## Goal

BL-98 / REQ-PANE-1 (RV-31, cut from `229_R7PANE.1`'s scope): pane split positions
(draggable dividers between the IDE panes) persist across sessions — per the repo's
existing UI-state convention (read what R7PANE.1 landed: the local storage / twin-backed
UI-state seam it used) — and double-clicking a divider snaps the split back to its default.

- `229_R7PANE.1` shipped the pane shell + occlusion work — its run ledger
  (`docs/build/runs/R7PANE.1.md`) + the `spa/ide/chrome*` sources name the divider/panel
  structure and any `data-*` names (`U3.occlusion` legs exercise them).
