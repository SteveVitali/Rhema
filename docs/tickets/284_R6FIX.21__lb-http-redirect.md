## Defect (verified at 277_R6LOW.1; BL-121)

The external LB had only the `https-fr` forwarding rule (`portRange 443`) — `http://` requests to
the prod domains got no answer at all (connection silence, not a redirect).

## Change (infra/pulumi/compute.ts)

GCP-idiomatic three-resource redirect beside `https-fr`: a dedicated `URLMap` whose only action is
`defaultUrlRedirect { httpsRedirect: true, stripQuery: false, MOVED_PERMANENTLY_DEFAULT }` (the
query is preserved — `?next=` deep links survive the upgrade), a `TargetHttpProxy` on it, and a
`http-fr` `GlobalForwardingRule` `portRange 80` on the same `lbAddress` (adopted reserved address on
ruled stages, managed/ephemeral elsewhere — mirrors `https-fr`'s conditional). Applied on every
stage uniformly — a preview's http URL redirects rather than hangs.
