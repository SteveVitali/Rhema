## Defect

audit (RH-0, GHSA-965c-763c-88jm on better-auth, 2026-11-15). Operator ruling 2026-11-16:

## Implementation

- `scripts/check-dep-audit.mjs` (`pnpm check:dep-audit`): runs `pnpm audit --prod --json` against
  the committed lockfile (no install needed — runs on every head), classifies each advisory
  against `scripts/dep-audit-baseline.json`, and fails on any **new or severity-escalated**
  high/critical advisory absent from the baseline.
- `scripts/dep-audit-baseline.json`: the 23 >=high advisories present at gate arm, each
  `status: pending-triage` — honest classification, NOT silent acceptance (accepted entries
  require a cited operator security ruling). Mirrors the `licenses.exceptions.json` convention.
- `.github/workflows/ci.yml`: always-run public-safe step after the demo-corpus gate — the
  registry re-query means a newly-published GHSA reds the next run on any head, per the BL row.
- Honest floor: `--prod` scope + baseline keeps the ~99 dev/transitive findings out of the
  failing class while printing the full severity table on every run.
- Deferred per ruling: the Renovate-style auto-PR arm (needs a token/permissions ruling) and the
  osv.dev second source (adds a CI network dependency for marginal coverage).
