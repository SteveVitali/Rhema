## In scope — deliverables
1. **Batch b migration** (REQ-KIT-3; UXC-16 for these files).
   - The SPA run-sheet surface, export, and the import and new-project surfaces as they stand
     after 235/236 move to the 225 primitives. Native radios become RadioCards / RadioGroup;
     selects become Select; checkboxes become Checkbox.
   - Inline literals go through `uiCss()`.
   - Hooks are preserved in the same change.
   - No-JS forms go on the exemption list with a reason.
2. **REQ-GUARD-1 enabled** for these files.
3. **One number formatter** (REQ-COPY-5; E1, D5). It lives in `@rhema/contracts` or
   `@rhema/ui` (the ticket's call; record it).
   - It covers credits, dollars, counts and rates, with no float noise ("0.023000000000000003" is
     impossible by construction).
   - Credits and $ appear together on paid surfaces.
   - It replaces ad-hoc `toFixed` / `toLocaleString` on the run sheet, export, usage and the
     shared `packages/ui/src/run-sheet.tsx` helpers. Only the helper call sites change; the file's
     control migration is 243's.
   - Value-claim callers keep 240's round-down semantics.
4. **Data-generated sentences** (REQ-COPY-5; D5).
   - The included-credit line is generated from the bucket model, so remaining can never exceed
     monthly as phrased.
   - The bucket expiry line cannot double "credits".
   - Both are covered by formatter / sentence tests.
5. E1's two near-duplicate pricing paragraphs in the run sheet are de-duplicated in passing, as a
   P2 inside a touched surface (`GD-UX-SCOPE.R7`).
