## Goal
The event store and its delivery path, as one concern: batched ingest, `run_events` persistence
with the visibility split and retention, Redis fan-out, and the SSE route with exactly-once
resumable replay.

## Load
- Spec §12.5 end-to-end (transport diagram; batching ≤250 or 2 s; disk buffer; >5,000 buffered →
  engine pause; `Last-Event-ID = seq` replay-then-tail; Redis carries only `{seq}` and is never a
  source of truth; daily partitions for `visibility=user` rows for the project's lifetime;
  `internal` rows in their own table, 30 days; viewer densities), REQ-ARCH-12/13, REQ-DATA-38,
  §13.5 (event-delivery SLO row), REQ-MOBILE-5 (mobile polls the same endpoint — shape only).

## In scope — deliverables
1. **Event writer:** the transactional append interface P0.08's state transitions and the
   run-task's batched `POST events` use; seq assignment; whitelist validation against P0.02's
   payload schemas at the write boundary (REQ-DATA-37's enforcement point).
2. **Storage:** `run_events` daily partitions (`visibility=user`, project-lifetime retention);
   `internal` rows in a separate table with 30-day retention jobs (review 13 F32).
3. **Ingest robustness:** batch limits, disk buffering in the run-task client when `api` is
   unreachable, the >5,000-buffered engine-pause signal, drop-nothing guarantee.
4. **Fan-out + SSE:** Redis `PUBLISH run:<id> {seq}`; `GET /runs/:id/events?after=seq` SSE over
   HTTP/1.1 through the ALB (idle timeout raised; `: ping` every 25 s); replay rows > after
   (`visibility=user` only) then tail; p95 ≤ 2 s target with no buffering on the route
   (REQ-ARCH-12/13); viewers receive Summary density only (REQ-DATA-38's rule; roles are 1.x —
   enforce the density parameter now).

## Out of scope (do NOT do here)
- Event *emission* and state transitions (P0.08); the mapper (P0.06); UI consumption (PRB.04+).
- Notification fan-out (PRB.09) and inbox items (P1.19).

## Acceptance criteria
- [ ] SSE reconnect with `Last-Event-ID` replays exactly-once (dup/gap test across a forced
      disconnect). *(deterministic)*
- [ ] Internal-type leak test: no `internal` row is ever served on the SSE route (CI assertion +
      fixture) (REQ-ARCH-12). *(deterministic)*
- [ ] Redis outage fixture: tail degrades, replay-from-Postgres still serves; Redis is never read
      as a source of truth. *(deterministic)*
- [ ] Ingest under an unreachable-api window: events buffer to disk and land in order afterward;
      the >5,000 threshold raises the pause signal. *(deterministic)*
- [ ] Partition/retention jobs: `internal` rows expire at 30 days; `user` rows survive.
      *(deterministic)*
- [ ] A payload violating the P0.02 schema (or a >280-char free-text field) is rejected at the
      write boundary (REQ-DATA-37). *(deterministic)*
