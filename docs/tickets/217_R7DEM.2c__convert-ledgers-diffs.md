Finish the converter. Response ledgers and structure plans become validated sidecars. Each round's
What-changed is computed at build time from real diff and trace functions, and unlinked hunks are
shown as Unlinked, never linked by invention. A single pipeline entry runs every pass per project,
aborts on any validation failure, and is pinned by per-project goldens. Draft ledgers render raw,
and the upstream parser bug becomes a recorded deferral.

## In scope — deliverables
1. **Response ledger** `src/convert/response-ledger.ts` per R2 §2.4: `findingOrdinal` resolution
   (letter majors, minors positional or by override, second-read labels via 216's reconciliation,
   open questions → roadmap finding); first-keyword disposition kinds with the declared mappings;
   status mapping; verbatim `rationale` for rebut/escalate; `moveOrdinal` from a `Discharges`
   column; `moves[]` from the plan table; evidence anchored into v(N+1) via the 215 ladder; one
   entry per finding (first-listed row). Rows that resolve to no finding are **raw-table-only**
   (216's default) and all rows, representable or not, go to `rows.json` for the raw ledger view.
   (REQ-CONV-10, REQ-CONV-16 consumer)
2. **Override kinds** added to the 215 mechanism: minor-row → finding map, mixed dispositions, and
   (only where a source table states it) move linkage. No hand-authored move map is introduced
   without a spec amendment: rounds without linkage stay Unlinked. (REQ-CONV-6 extension,
   REQ-CONV-15)
3. **Structure plan** `src/convert/structure-plan.ts` per R2 §2.5 (spine, sections; no anchors; the
   rest raw). (REQ-CONV-2)
4. **Draft ledgers render raw**: no draft-ledger sidecar, and the converter never imports
   `parseDraftLedgerSections` (a test pins this). Open a new DEFERRALS row, `D-R7DEM.2c-1`, for
   the parser bug (Roman-numeral `#` cells read 1 of 17–18 rows). It cross-references the BL id
   that 209 seeded from spec §7. It carries **owner** `253_R7REC.1` and its **opened date**
   (`date -u +%F`), with the unblock condition "253 R7REC.1 closes it to BACKLOG". That keeps a
   round-7-scoped OPEN row from blocking GATE-ACCEPT.R7 (P4-22). (REQ-CONV-17)
5. **What-changed** at build time (REQ-CONV-15): per round, `diffMarkdown` (vN → vN+1, sanitized
   drafts) plus `traceRevisionMoves` over the response-ledger entries/moves, emitted as a
   deterministic artifact 218 projects. A hunk with no trace is explicitly `Unlinked`; a test
   proves no link is emitted without an entry carrying both `moveOrdinal` and an anchor.
6. **Pipeline** `src/convert/index.ts`: per project dir, run all passes in order, pass **every**
   sidecar through `parseSidecar`, abort with no partial output on any `failed`, and enforce that
   every override row in the project was consumed. (REQ-CONV-2, REQ-CONV-6)
7. **Golden harness** (REQ-CONV-12 amended): per project under the 214 layout, canonical-JSON
   byte equality for every sidecar, `labels.json`, `rows.json` and what-changed artifact; the
   summary-count reconciliation assertion; the zero-unmapped verdict/disposition/status lists;
   anchor-rung histograms; the stale-override failure. It runs on the synthetic fixture in every
   PR, and is the same harness 219 points at the real projects.
