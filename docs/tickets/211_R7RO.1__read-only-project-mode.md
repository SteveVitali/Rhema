## Goal
One client read-only mechanism, `ReadOnlyProject{reason:"demo"|"showcase"|"run_lock"}`, is carried in boot and the JSON twin. It hides or disables every write control before any request is made, with one notice per reason and the server guards kept as defence in depth. The seeded Showcase stops being a forced-SSR multi-page site. Its Page family renders in the SPA through this mechanism, so in-app hops from it are client navigations. This ticket owns the mechanism. The demo reason's wiring of data sources, boot and side-effect gates belongs to 220, 220a and 221.
