# P0.05 — Boundary hooks and seat policy (`packages/hooks`)

- **Sequence:** 5 of 50
- **Phase:** 0 — Foundations
- **base_branch:** current checkout (stacked PR chain)
- **Depends on:** P0.02 (agent-type policy data, contracts)
- **Run:** `implement-spec spec=docs/tickets/05_P0.05__boundary-hooks.md`

## Goal
The tool layer of the three concentric boundary layers (§12.6): one hook package, same code for
every seat and engine, policy as per-run data — path classification, URL policy, denial semantics,
and the append-only audit trail.

## Load
- Spec §12.6 (mount/tool/URL layers; seat mount tables; denial thresholds), §11.3
  (`AgentType`/`AccessLogEntry`/`FetchLogEntry` shapes), §12.2 (judge-class `Agent` rejection),
  §12.10 rows 1–4 (guarantee preservation), REQ-DATA-11/12/13/15, REQ-ARCH-17/18.

## In scope — deliverables
1. **`PreToolUse` hook** (matcher `Read|Write|Edit|MultiEdit|Glob|Grep|Bash|WebFetch|WebSearch`),
   running as uid `harness`: realpath resolution (no symlink/`..` escapes; Bash argv tokens
   included), classification against the seat's readable/writable globs, deny out-of-namespace
   reads and read-only writes with a one-line reason, deny recursive operations over the root,
   URL checks against the run's policy (hold-out deny; user exclusions; calibrator allow-after-
   prediction rule as policy data), reject `Agent` in judge-class phases, `access_log` row per
   decision (REQ-DATA-11; REQ-ARCH-17/18).
2. **Denial semantics:** three denials of one path abort the step `failed(boundary)`; >20 denials in
   a phase → `run.hiccup` + one guided retry (data returned to the orchestrator; the orchestrator
   acts on it in P0.08).
3. **Policy-as-data:** seat policy (readable/writable namespaces, persona view, tool set) loaded
   from `agent_types` rows per run; subagents inherit hooks (same process tree) and are attributed
   by `agent_id` (REQ-DATA-12); the allowed-path set rendered for subagent prompts (REQ-DATA-13,
   belt-and-braces).
4. **Audit:** append-only `access_log`/`fetch_log` writers (via the harness-side client — the
   transport is P0.06/P0.08's internal API; here define the write interface + buffering), 90-day
   retention semantics documented (REQ-ARCH-18, REQ-ARCH-29).
5. **Policy test-suite:** table-driven tests over every seat × path-class × tool combination from
   the §12.6 seat tables, including: Editor never reads `agents/author/**` or
   voice-print/lexicon/exemplars; persona-builder/calibrator server-side `web_fetch` disabled
   (fetch via client-side fetcher only — REQ-DATA-15 amended); `preferences.md` mount point never
   readable by Editor-seat policy (REQ-OBJ-10's hook-layer half).

## Out of scope (do NOT do here)
- The mounts themselves (materialization is P0.09; kernel read-only mounts are P0.06's image).
- The proxy's URL enforcement (P0.07) — the hook is the in-container layer.
- Orchestrator reactions to denial counts (P0.08).
