## Goal

Editing stops being a debounced POST. Keystrokes land in a Y.Doc backed by y-indexeddb
(survives refresh/crash), synced through the self-hosted Hocuspocus service in `apps/collab`,
materialized to canonical markdown + restore points server-side. The only UI is the sync pill;
there is no Save button, no unsaved-changes dialog, no `beforeunload` prompt — `⌘S` marks a
named restore point (REQ-IDE-43). Single-user at MVP; the Redis scaling extension arrives with
sharing roles (§13.1).

## In scope — Stage A (code + tests, PR-able)

1. **The real Hocuspocus server in `apps/collab`.** A WSS endpoint serving documents named
   `draft:<draftId>` (one live doc per working head). `onAuthenticate` resolves the session and
   authorizes the workspace membership + document against the draft's project — the
   REQ-DATA-44 auth-hook half (role checks in the collab auth path; REST mutations keep their
   existing audit rows; the sharing-roles matrix itself is 1.x — MVP admits the workspace's
   own members). `onStoreDocument`/debounced persistence writes `live_docs.y_state` +
   `state_vector`. No auth = no socket.
2. **Materialization.** On debounce and on restore-point triggers, the server serializes the
   Y.Doc through P1.02's `PM → md` (the canonical serialization), stores the artifact version
   content-addressed, and stamps `live_docs.md_sha256` + `materialized_at`. Materialization
   never mutates a frozen head and never writes while a run holds the lock — a frozen or
   run-locked doc must refuse mutations at the *service* layer (read-only provider + rejected
   updates), not just render read-only UI.
3. **Restore points (REQ-IDE-34's storage half — the UI is P1.08).** Triggers: every 5 min of
   activity, on blur/close, before any run, and `⌘S` (named). Stored as **Yjs update deltas
   chained from a daily full snapshot** under `restore/<ydoc>/<ts>` in the content store +
   `restore_points` rows (`kind` = snapshot|delta, `cause` = timer|blur|pre_run|named, `label`
   for named). Reconstruction = load latest snapshot + apply deltas in order. Retention per
   plan per ledger F12 — land the per-plan retention table in config + a sweeper, even if the
   plan rows are simple (e.g. named points kept, deltas expire per plan window); document the
   values used.
4. **The client transport.** A `YjsTransport` implementing P1.02's `EditorTransport`: Y.Doc ←
   y-indexeddb persistence ← Hocuspocus provider. The sync pill consumes provider status +
   local pending-update count: `synced ✓` · `syncing…` · `offline · n changes queued` (amber) ·
   `read-only`. `⌘S` marks a named restore point (a route/WS message that flushes a delta
   with `cause=named` + label). Same user on two devices merges silently — that is Yjs, prove
   it in a test.
5. **Conflict semantics (REQ-IDE-46 amended).** Non-prose records keep the existing
   `If-Match` → 409 + inline "Updated elsewhere · Reload / Keep mine" pattern (unchanged —
   assert it still holds on the surfaces that carry it). Edits made offline to a version that
   froze meanwhile land in a **new working head** `v(N+1) human_revision` on reconnect, with an
   explanatory banner — the diverged Y.Doc's pending updates apply to the fork, never silently
   overwrite the frozen version.
6. **The block-patch service schema (M17 — schema now, consumers 1.x).** Define the contract
   REQ-MOBILE-6 consumes: the working doc as blocks `{blockId, kind, markdown, hash}` (P1.02's
   sidecar supplies ids/hashes); `PATCH`-shaped apply of `{baseHash, markdown}` by a headless
   ProseMirror step in collab as one Yjs transaction tagged `human/mobile`; 409 on hash
   mismatch; refusal on frozen heads. Land the typed contract + the headless-PM apply path in
   collab behind the same auth hook; the mobile client arrives 1.x.
7. **Cutover.** The Page's `EditorTransport` swaps from the beta save-POST impl to
   `YjsTransport`. The `POST /editor/:draftId/save` path may remain for the dormant CodeMirror
   surface but the Page never calls it. Keep `sync-machine.ts`'s pill vocabulary if it still
   describes the states honestly; delete what no longer runs.
8. `turbo build lint typecheck` + `pnpm test` green; new deps (yjs, y-indexeddb,
   y-protocols, @hocuspocus/*) checked against `check:licenses` (all MIT — verify).

## Acceptance criteria

- [ ] Two Yjs providers over the collab server converge to one doc; a kill-and-reconnect
      client resumes from y-indexeddb + server state. *(deterministic — in-process Hocuspocus
      test utilities are fine)*
- [ ] Debounced materialization produces the canonical markdown + `md_sha256`; a frozen or
      run-locked doc rejects mutations at the service layer. *(deterministic)*
- [ ] A restore point reconstructs byte-identical markdown from snapshot + deltas; `⌘S` writes
      a named point; the per-plan retention table + sweeper exist. *(deterministic)*
- [ ] An offline edit to a since-frozen version lands in `v(N+1) human_revision` with the
      banner — the frozen version's bytes never change. *(deterministic)*
- [ ] The auth hook rejects a socket without a session and one for another workspace's doc.
      *(deterministic)*
- [ ] The block-patch contract exists with its typed apply path (409 on hash mismatch, refusal
      on frozen heads) — schema + service test, no mobile consumer. *(deterministic)*
- [ ] No Save button, no unsaved-changes dialog, no `beforeunload` anywhere on the Page.
      *(deterministic)*
- [ ] Stage B evidence in the run ledger; no new OPEN deferral without a `D-P1.03-*` id.
      *(operator-gated)*
