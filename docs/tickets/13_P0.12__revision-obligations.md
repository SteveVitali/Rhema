## In scope — deliverables
1. **Spawn (REQ-OBJ-2), inside the P0.09 delivery transaction, actor `system`:** every
   blocking/major finding → exactly one obligation (unique per root finding); `minor` on
   accept/adapt disposition only; `note` never; escalation keeps open + links the
   `decision_request`; reconciliation-rejected spawn nothing unless promoted; `source:
   'agenda'`/`'user'` rows (manifest agenda; "Add to obligations" API; palette source later).
2. **Routing + discharge (REQ-OBJ-3):** disposition-driven transitions (rebut closes with
   DB-checked rationale; defer parks with horizon — `next_review` default, 1–3 rounds, `pre_export`;
   horizon arrival returns to `open`); `addressed` from frozen response-ledger moves; `discharged`
   via covering-review no-match, gap-check verification (`verifiedBy`), or by-hand with required
   note ("discharged (unverified)"); `mooted` per REQ-DATA-26 with confirm-at-next-triage;
   `reopened` on a regression match with `roundsOpen` increment; export/archive never block.
3. **Lineage (REQ-OBJ-4):** the three matchers in order at review delivery — claim identity
   (`normalized_url` + quote), the Editor's `carriesObligationId` declaration (re-review mirror
   gains read-only `obligations.json` in the letter-writing context only — with P0.09's
   materializer; never the second read), anchor overlap above a confidence floor (may ship
   flag-gated behind 1–2 while tuned); all recorded on `obligation_findings`.
4. **Derived counts + stall:** REQ-WF-7's carried/closed/new computed from rows at delivery and
   asserted against sidecar counts (mismatch → delivery-validation warning); the §6.8 stall query
   (`severity in (blocking,major) and roundsOpen ≥ 2 …`) as a shared, tested query feeding the
   Decisions inbox (REQ-OBJ-5); Convergence-report reads noted as 1.x consumers.
5. **Read APIs** for the beta surfaces: per-version open-obligation chips, per-finding obligation
   state, run-sheet scope lines ("4 open obligations will be checked"), export-dialog counts
   (REQ-OBJ-6 data).
