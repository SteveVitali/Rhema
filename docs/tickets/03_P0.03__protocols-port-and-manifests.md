# P0.03 — Skill port and phase manifests (`packages/protocols`)

- **Sequence:** 3 of 50
- **Phase:** 0 — Foundations
- **base_branch:** current checkout (stacked PR chain)
- **Depends on:** P0.02 (sidecar schemas, enums). Lands in the **private** protocols checkout wired by P0.01.

## Goal
The product's substance: the `~/agent-discourse` skills ported verbatim into `packages/protocols`
with the six harness-neutral inputs and the structured outputs, plus the phase manifests that let
the orchestrator run them one phase per `query()`.

**Port scope (validation-first / beta path, §17):** `editorial-review` (Review), `respond-to-review`
(Revise), `fact-check-only` (phase-subset of Review, REQ-WF-13), and `bootstrap-persona` (Quick
Voice tier). **`draft-from-outline`, `outline-from-research` and `research_burst` are deliberately
deferred to the full-IDE phase** (the beta's Phase 0 defers Draft's port — §17 reconciliation
paragraph; design/18 §2.3). bootstrap-persona's Full-Profile path (census, Approve sample, hold-out,
calibration) is ported but may be exercise-gated; Quick tier must work end-to-end.

## In scope — deliverables
1. **Ported skills** differing from upstream **only** by: the `phase` / `scope` / `changed_since` /
   `prior_review` / `resume_from` / `sidecar` inputs, the `.rhema/phase-result.json` output, the
   Q-11 edits (REQ-ARCH-8: drop `usage=study` default + report, the non-self quotation-bound
   `positions.md` rule, the docs/-enlargement sentence), and the persona-resolution edit; sidecar
   emission behind `sidecar: true` so upstream stays usable (REQ-ARCH-5 amended; departure C11).
   Skills emit the severity vocabulary explicitly in the findings sidecar (REQ-SPEC-4) and, for
   re-reviews, may declare `carriesObligationId` (REQ-OBJ-4 skill-side).
2. **Phase manifests** (`packages/protocols/manifests/<workflow>.ts`) for review, revise,
   fact_check, profile_voice/refresh_voice/calibrate_voice: the §12.2 fields verbatim
   (`key, index, label, skillPhase, seat, artifacts[], predicates[], sidecars[], gateAfter?,
   optional?, phaseClass, parallelGroup?, maxIterations?, budgetShare, backEdges?, allowsSubagents`),
   with the §12.2 predicates (claim rows ≥ inventory; letter sections complete; second read
   producer-checked; response-ledger one row per finding) as data the orchestrator evaluates
   (REQ-ARCH-6, REQ-SPEC-13's data half).
3. **Estimator constants** as versioned data per the §12.2 shapes (provisional, flagged as such
   until P0.15's instrumented runs — §16.3 #1).
4. **Protocol seeds:** the `Protocol` object (§6.7 type) with the **Essay** protocol row seeded
   (plus any protocol the three real-project fixtures require); Academic/Op-ed/Memo rows land in the
   full-IDE phase (Q-22 beta is Essay-only; Q-15 scope untouched).
5. **Upstream-diff CI job:** diff `packages/protocols/skills/*` against the pinned upstream commit;
   only the sanctioned deltas may appear (REQ-ARCH-5).
6. **Path→kind map** (ledger F11) for the harvester, versioned with the manifests.
7. **Closed input-source schema (REQ-OBJ-11):** the protocol package declares its allowed input
   sources (venue tables, §18 results, run inputs — never anything derived from `dispositions` or
   any reception of Editor output feeding review configs, severity thresholds, phase prompts or
   rubric anchors); a CI contract test enumerates the allowed sources the way REQ-ARCH-33 greps
   client bundles.

## Acceptance criteria
- [ ] Upstream-diff job green: only the sanctioned inputs/outputs/Q-11/persona edits differ
      (REQ-ARCH-5). *(deterministic)*
- [ ] Each manifest's `index` order equals the skill's own fallback order (Review: intake, craft,
      verification, discourse, second read, argument, letter — review 13 F17). *(deterministic)*
- [ ] Judge-class phases declare `allowsSubagents: false`; every back-edge is declared
      (`grounding→plan` n/a here; `revise→triage` present) (§12.2). *(deterministic)*
- [ ] With `sidecar: true`, a recorded run of each ported skill on a real-project fixture emits
      sidecars that validate against P0.02's schemas. *(agentic — needs one live run per skill;
      budget-capped; the full three-project matrix is P0.15's job)*
- [ ] With `sidecar` absent, the skills run unchanged against upstream conventions (spot-check by
      diff + one dry run). *(agentic)*
- [ ] `phase: "N"` runs exactly phase N then stops, writing `.rhema/phase-result.json`. *(agentic)*
- [ ] Essay protocol row seeds with `verified_at`-bearing venue-bar config per §6.7. *(deterministic)*
- [ ] REQ-OBJ-11 CI test: a planted disposition-derived parameter in a protocol config fails the
      input-source enumeration. *(deterministic)*
