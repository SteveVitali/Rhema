## Goal
`renderSpaShell` emits the §3.1 head contract (themeCss/ideCss, nonce'd themeBoot, `docMetaFor` title for the requested path, favicons, viewport, `data-theme`/`data-device`/`data-project`, mount node, `<noscript>`, `data-renderer="spa"`, `data-spa-boot` embed, Vite-manifest entry tags).
