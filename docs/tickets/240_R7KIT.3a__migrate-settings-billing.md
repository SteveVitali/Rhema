## In scope — deliverables
1. **Batch a migration, settings / billing / usage** (REQ-KIT-3; UXC-16 for these files).
   - Every `<button|input|select|textarea>` in settings / billing / usage becomes a 225 / 225a
     primitive (Button / IconButton / TextField / TextArea / Select / Checkbox / RadioGroup /
     Switch / RadioCards).
   - Inline spacing / type / colour / radius literals go through `uiCss()` classes or tokens.
   - The DOM-contract hooks are preserved, and any rename lands in `dom-contract.ts` in the same
     change.
   - Hidden inputs and no-JS-only forms go on GUARD-1's named exemption list with a reason each.
2. **REQ-GUARD-1 enabled** for these three files, via the per-batch config (RV-16). 240a adds
   `voices.tsx` to the same batch-a block.
3. **Sessions read "Chrome on macOS · this device"** (REQ-KIT-4; D3). A tested UA → label parser
   handles unknown agents with a fallback, and marks the current session.
4. **Enum keys render as labels** (REQ-KIT-4; D4). Settings option keys render here, through
   COPY-owned label maps. The voice source-kind map (e.g. `substack_export`) is authored here too,
   so 240a only consumes it on the voices surface. 244 later folds these maps into the single label
   table.
5. **Plan-value lines round down** (REQ-KIT-4; D8, RV-28; spec §8.2).
   - `planCoverageLine` emits "less than 1 essay review a month on Base" for a figure below 1, and
     rounds every other figure down.
   - The divisor stays the raw estimator figure (R6MNY.1, unchanged).
   - It is formatter-tested against `pricing.json` for every gated plan and tier.
   - There is no money-mode change.
6. **Public `/pricing` delta, accepted** (REQ-DACC-6 as extended by `GD-PUBDELTA.R7`; Phase-4
   P4-9). The round-down is visible on public `/pricing`. The operator accepted it as an enumerated
   DACC-6 delta ("Accept both (Recommended)"). This ticket re-captures `public-ssr-baseline`
   locally against its own build and commits the before/after diff in the run record. Only the
   plan-value lines may differ.
