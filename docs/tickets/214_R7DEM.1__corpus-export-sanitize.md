## Goal
Make the four-essay corpus exportable, sanitized and provably clean **before** any real byte enters
the (public, permanent) git history. This ticket lands the `@rhema/demo-corpus` package, the
deterministic exporter and sanitizer with its denylist gate, the PROVENANCE writer, the committed
**synthetic** mini-corpus every later demo test uses, and the CC BY-NC-ND 4.0 content carve-out.
Every gate is proven on the synthetic fixture. Running the tools against the real source, the
one-time Published fetch, and producing the HUMAN-H14 review packet are 214b_R7DEM.1b's.

## In scope — deliverables
1. **Package `packages/demo-corpus`** (`@rhema/demo-corpus`) per the AGENTS.md add-a-package rules
   and R4 §3 New-package checklist: `type: module`, `build`/`typecheck`/`lint` scripts, tsconfig
   extending `../../tsconfig.base.json`, root `tsconfig.json` reference, a root `AGENTS.md`
   work-area row and a scoped `packages/demo-corpus/AGENTS.md` that records the directory layout
   (Notes § Layout) and the "corpus is data, never TS literals" rule. (REQ-CORPUS-6, REQ-DOPS-3)
2. **Corpus location** (REQ-DOPS-1, corpus half; P4-18). Corpus content lives only in
   `packages/demo-corpus`, never under `apps/web/src/spa`, `copy.ts` or `docs/`. A unit test fails
   if a tracked file outside the package carries a corpus artifact. It checks the layout path
   patterns, plus every per-file sha256 from the synthetic `export-manifest.json`. The `demo.*` COPY
   family and the `FUNNEL_SCOPE` half are 222_R7DEM.6a's.
3. **Allowlist-only ingest** using R1 §1 globs plus the spec §4.1 REQ-CORPUS-11 file-ruling table
   (RV-37). Anything outside the allowlist — `outline/**`, `manifest.md`, `agents/editor/notes.md`,
   `voice-charter.md`, dotfiles, SPD `short-v1.md`, `values-table*.png`, the GM fragments and
   `01-claim-ledger-{A,B}.md` — is excluded with a recorded reason; an un-ruled file fails the
   export. (REQ-CORPUS-1, REQ-CORPUS-11)
4. **Sanitizer + redaction table**: rewrites only, each recorded (pattern → replacement, file,
   line, reason); no blind token replacement; draft prose changes only for the SPD `figures/`
   image-path fix; URL guards (`[?&]utm_*` strip, `r.jina.ai` prefix unwrap) run before any
   `normalizeUrl` consumer. Generic rules are committed code. File-targeted rewrites are **data**
   read from the withheld `corpus/_rules/` path through a typed reader this ticket owns; the
   synthetic fixture carries its own file-targeted rules to test the reader. The real
   `_rules/` data (e.g. the workflow-sense "operator" → "the writer" lines) is 214b's.
   (REQ-CORPUS-3 as amended by S-10)
5. **Denylist gate** (hard fail) over every corpus-derived output — corpus, goldens, snapshots,
   real and synthetic — with R1's pattern list; bare `Steven`/`Desktop`/`claude`/`operator`/
   `@example.com` are **not** gated; line-allowlist entries name file and line only (no quoted
   text), and a stale entry fails. The Published credit lines are allowlisted that way, never
   altered (S-11); the real entries are 214b's data. Exposed as a root `pnpm check:demo-corpus`
   script, wired into CI's `public-safe` job (always-run, alongside gitleaks).
   (REQ-CORPUS-2 as amended)
6. **Image sanitization**: PNGs re-encoded or chunk-stripped to drop EXIF/XMP/tEXt beyond what
   rendering needs; filesystem xattrs never travel (bytes are copied, not files). The synthetic
   fixture's exported image is byte-pinned. No new dependency unless `check:licenses` passes it.
   (REQ-CORPUS-5)
7. **Excluded-reference markers**: references to excluded files are detected and recorded so the
   renderer can show a non-link labelled "not published"; the text is never deleted.
   (REQ-CORPUS-4; rendering is 221)
8. **Per-artifact files**: one output file per source artifact; source notes stay individual files
   with an index, so later payloads can load lazily. (REQ-CORPUS-9, corpus half; snapshot
   chunking + size assertion is 218)
9. **`PROVENANCE.md` writer** (REQ-CORPUS-11): source identity (agent-discourse HEAD for context
   **plus** a sha256 tree digest of the allowlisted input bytes, since `agent-scratch/` is
   untracked upstream) and export date; the allowlist with counts; the applied redaction table;
   the excluded set with reasons; the Published entries; and a structured, sanitized
   **round/approval facts** block (the only facts S-9 / REQ-CORPUS-7 may cite — authored from the
   round logs without rendering them; anything not stated there is "not recorded"). Plus an
   `export-manifest.json` (per-file sha256 + one manifest digest) that H14 signs and 219 verifies.
   (REQ-CORPUS-7 data half, REQ-CORPUS-11)
10. **Version metadata and the Published data shape** per essay: each version's label,
    title/subtitle (so the v1/v2 → v3 retitle is data, RV-30), origin, and the
    **"Writer-directed edit (not reviewed)"** label on SPD v3/v4 and CoR v4 (S-10). The final
    **Published** node: `published.md` with URL, fetch date and sha256, label "Published ·
    sjsebastian.substack.com · fetched YYYY-MM-DD", origin `imported`, and the live URL link. The
    exporter ingests a `published.md` through the same sanitize + denylist path; this is proven on
    the synthetic `published.md`. (REQ-CORPUS-13; REQ-CORPUS-12 data shape; REQ-CORPUS-8 data half)
11. **`tools/demo-corpus/export.mjs`**: deterministic CLI (no clock except the recorded export
    date input, sorted output, byte-stable re-runs) over the package's export modules; default
    output is the withheld path. (REQ-CORPUS-11)
12. **Synthetic mini-corpus** `packages/demo-corpus/fixtures/synthetic/` (S-12, REQ-CORPUS-15):
    an invented essay with non-real names, ≈ 1.5k words, in **both** the source layout (with
    excluded-file decoys) and the exported layout (the exporter's own golden). It covers every
    artifact shape the four projects have and every R2 §1 parse variant, including those the spec

    `published.md`, file-targeted `_rules/`, and PROVENANCE facts. A committed coverage table maps
    each variant to its fixture file. Denylist negative controls are synthesized **in-test**
    (tmpdir, string assembly), never committed as literal identity tokens.
13. **Licence carve-out** (REQ-DOPS-3, ADR-127): `packages/demo-corpus/LICENSE` (CC BY-NC-ND 4.0
    legal code), the package `license` field covering data and code, a `"type":"asset"` entry in
    `licenses.exceptions.json`, and a new appended `LICENSES.md` section ("Content outside the MIT
    grant": path, licensor "S. J. Sebastian", scope). `licenses-doc.test.mjs` stays green. Fill the
    ADR-127 body R7OPEN.1 shelled (the landing-recording asset declaration section is 249a's).
14. **Withholding tripwire**: `packages/demo-corpus/.gitignore` withholds the real-data paths
    (`corpus/**` incl. `_rules/`, `snapshots/**`, the per-project real goldens) with a dated comment
    ("withheld until HUMAN-H14; 219_R7DATA.1 removes"), and a unit test fails if any file under
    those paths is tracked while that marker is present (guards `git add -f`).
