# P0.04 — Sidecar parsers, gate serializers, `protocols_version`

- **Sequence:** 4 of 50
- **Phase:** 0 — Foundations

- **Depends on:** P0.02 (sidecar schemas), P0.03 (skills + manifests + path→kind map)

## Goal
The two mechanical halves that make files and rows interchangeable: **parsers** (sidecar + markdown →
rows; ledger F10) and **serializers** (post-gate rows → the exact files the next phase reads;
REQ-SPEC-9) — golden-tested as inverses — plus the contract test and versioning that make protocol
drift impossible to ship silently (REQ-SPEC-22).

## Load
- Spec §11.1 (sidecar contract; sidecar authoritative; mismatch = validation failure), §11.5
  REQ-SPEC-9 (serializers as the exact inverse of the parsers; overlay flow summary — the runtime
  overlay mechanics belong to P0.10), §12.2 REQ-SPEC-22 (manifest ↔ SKILL.md contract test;
  `protocols_version` = skill sha + manifest + parsers/serializers, recorded per run), ledger F10/F11.

## In scope — deliverables
1. **Parsers** in `packages/protocols/parsers/`: `findings.json`, `01-claim-ledger.json` (+ stance
   edges → `claim_sources` rows, REQ-OBJ-18), `rubric.json`, `response-ledger.json`,
   `structure-plan.json`, `cut-list.json` → typed rows; markdown ↔ sidecar cross-check (a mismatch
   is a validation failure, REQ-SPEC-12); `parseStatus: ok | failed` only — no partial (REQ-DATA-7
   amended).
2. **Serializers** in `packages/protocols/serializers/`: `rows → response-ledger.md (+ .json)`,
   `rows → structure-plan.md (+ .json)`, `rows → cut-list.md (+ .json)` — golden-tested for
   round-trip (`parse(serialize(rows)) ≡ rows`) on the three real projects (REQ-SPEC-9).
3. **Manifest ↔ SKILL.md contract test** (REQ-SPEC-22): extract phase headings, artifact filenames,
   opt-out flag names and sidecar names from each ported `SKILL.md`; assert equality with the
   manifest, the path→kind map, the parsers and the serializers.
4. **`protocols_version`:** one version stamped over the trio (skill shas + manifests +
   parsers/serializers), exposed to the deploy-provenance record (P0.01) and to runs (consumed by
   P0.08: a run resumes only on its own `protocols_version` + image digest).
5. **Golden-set bootstrap:** parser fixtures from the three real dossiers (ledger F10); the
   grows-automatically hook (every green nightly dossier becomes a fixture) as a documented
   mechanism the nightly runner (P0.15) wires up.

## Out of scope (do NOT do here)

- Skill edits (P0.03). Editor/UI rendering of any of this.
