# P0.01 — Monorepo, SST stages, core infra, CI

- **Sequence:** 1 of 50
- **Phase:** 0 — Foundations (validation-first sequence, spec §17)
- **base_branch:** `main` (first ticket of the stacked chain)
- **Depends on:** — (Phase 0a human prerequisites: AWS account, domains, Secrets Manager entries — see 00_MANIFEST.md)
- **Run:** `implement-spec spec=docs/tickets/01_P0.01__monorepo-and-infra.md`

## Goal
The empty-but-deployable skeleton every later ticket lands in: the pnpm + Turborepo monorepo with the
spec's package layout, SST v3 stages, the core AWS substrate (Aurora Serverless v2, S3, Redis, ECS
scaffolding, VPC with the no-IGW sandbox subnet), Better Auth (Google + magic link), and the five-job
CI pipeline including the licence policy and public-safe checks.

## Load
- Spec §13.1 (stack), §13.2 (repository layout, stages, CI/CD, open-source-ready hygiene), §12.1
  (service inventory and VPC topology — provision the skeleton; services themselves land later),
  §13.3 (secrets placement, tenancy posture), §17 Phase-0 row.
- Q-3 / Q-19 rulings (Appendix B.1): TypeScript everywhere, no Python; closed-source but
  open-source-ready.

## In scope — deliverables
1. **Monorepo layout** exactly per §13.2: `apps/{web,api,collab,worker,run-task,fetcher,convert,egress-proxy,export,mobile}`
   and `packages/{contracts,db,engine,hooks,harness,protocols,protocols-stub,measure,figures,ui,api-client,tokens,findings-core,markdown-view}`,
   `infra/`, `evals/`, `evals-stub/` — stubs/placeholders where the real code lands in later tickets;
   pnpm workspaces + Turborepo with Bazel-compatible invariants (explicit per-package deps, project
   references, no cross-package relative imports — lint-enforced); Turborepo remote cache self-hosted
   on S3 (never Vercel-hosted).
2. **Private-package resolution (REQ-ARCH-37 amended):** `@rhema/protocols` and `evals/` resolved by
   path to a separate private checkout when present, falling back to `packages/protocols-stub` /
   `evals-stub/`; never git submodules; the `public-safe` CI job builds stub-only.
3. **SST v3 stages** `dev` / `pr-<n>` / `prod` per §13.2: prod Aurora ≥ 4 ACU floor, previews 0-ACU
   auto-pause, isolated preview buckets, `max_usd`-style preview guards wired as config; VPC with the
   private sandbox subnet that has **no IGW/NAT route** (REQ-ARCH-2), subnets sized /20; IAM as code.
4. **Better Auth** self-hosted in our Postgres: Google OAuth + email magic link; sessions; device
   list schema stub (§13.1).
5. **CI (GitHub Actions)** per §13.2: `typecheck/lint/unit` → `contracts` → `integration` →
   `images` (build+scan, pin digests) → `public-safe` (gitleaks; protocol-marker grep placeholder;
   licence allowlist MIT/Apache-2.0/BSD/ISC failing SSPL/BSL/AGPL, **plus a checked-in exception list
   with a rationale per package**: `@anthropic-ai/claude-agent-sdk`, pandoc, fonts) — jobs may start
   as thin placeholders that later tickets fill, but the pipeline and the licence/exception documents
   (REQ-ARCH-40, `LICENSES.md` incl. the SDK's commercial terms and the "hosted under our brand,
   never 'Claude Code'" rule) are real now.
6. **Deploy provenance (REQ-ARCH-39):** every deploy records `{git_sha, image_digests, protocols_version,
   rate_table_version}` in a `deployments` table/artifact (schema may be provisional until P0.02).
7. **Repo hygiene** (Q-19): MIT licence file, `SECURITY.md`, `CONTRIBUTING.md`, `LICENSES.md`; no
   user text in history; secrets only via Secrets Manager/SSM — no secret as an env var to `web`/`collab`.
8. **Backups, retention, deletion pipeline** (REQ-ARCH-28/29): Aurora continuous backups (35 days)
   + S3 versioning as infra config; the tombstone → 30-day purge → lifecycle-delete pipeline for
   project deletion and the 14-day-grace account hard-delete (anonymized ledger rows + Stripe
   customer retained per tax law) as `worker` jobs; the §13.3 retention schedule (transcripts 30 d,
   internal events 30 d, audit 90 d, usage/ledger 7 y, restore points per plan) as lifecycle
   rules/config consumed by later tickets. (Deletion *UI* is P1.20; the audit is P1.22.)

## Acceptance criteria
- [ ] `pnpm install && pnpm turbo build lint typecheck` green on a fresh clone **without** the private
      protocols checkout (stub resolution) and with it. *(deterministic)*
- [ ] `sst deploy --stage pr-test` stands up an isolated preview (0-ACU Aurora, isolated buckets) and
      tears down cleanly; `dev` stage deploys the skeleton services. *(deterministic)*
- [ ] Security-group/route-table test or assertion: the sandbox subnet has no route to an IGW/NAT;
      its only egress target is the (future) proxy's SG (REQ-ARCH-2). *(deterministic)*
- [ ] CI fails on: an SSPL/BSL/AGPL dependency not in the exception list; a gitleaks hit; a
      cross-package relative import. *(deterministic)*
- [ ] Sign-in with Google and magic link works on `dev`. *(deterministic)*
- [ ] `LICENSES.md` lists the SDK commercial-terms exception and the pandoc/GPL separate-process
      rationale. *(deterministic)*
- [ ] Deletion pipeline test: a tombstoned project purges at the 30-day mark (clock-advanced
      fixture); retention lifecycle rules exist for each §13.3 class (REQ-ARCH-28/29).
      *(deterministic)*
