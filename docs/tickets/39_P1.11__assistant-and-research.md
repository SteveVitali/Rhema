## Goal

The Assistant seat exists end-to-end per §7.1: project-scoped threads with durable source notes,
the per-turn plan card with hard budgets, typed `read_artifact` references, attachments through
the existing fetcher/convert path, a turn cost strip driven by events not model text — and the
two-conduit rule enforced structurally (chat output reaches a drafting pipeline only as an Outline
artifact or promoted Guidance; a chat turn never creates a draft or finding). Alongside it, the
Rhema-owned `research_burst` run — authored here, not ported — produces a distilled research note
with source cards under a plan-card cap, honoring the per-run URL policy and the proxy cap
(§16.3 #7 verified in-body and in Stage B).

## In scope — Stage A (code + tests, PR-able)

1. **The `assistant` AgentTypeConfig + `chat_turn` workflow.** Seed the agent-type row
   (reads/writes/denies/tools/defaultThreadTier `Base`/per-turn 40 cr · 5 searches · 10 fetches —
   the §7.1 numbers); a chat turn is a `chat_turn` run (one provenance, one cost meter, events on
   the project feed) that starts an assistant-seat phase under the compiled seat policy. Assert
   the mount policy end-to-end: writes outside `agents/assistant/**` are rejected; `agents/editor/**`,
   `HOLDOUT-*`, and unfrozen author ledgers are unreadable; `preferences.md` reads (REQ-OBJ-10's
   Assistant clause).
2. **Threads (REQ-CHAT-1…5).** Default "Project chat" created with the project, undeletable;
   named threads create/rename/archive/delete — delete removes transcript + brief + pins, retains
   `agents/assistant/research/` source notes (REQ-CHAT-4). Session state persists via the session
   store to `agents/assistant/threads/<id>/session/`; `brief.md` + `pins.json` per thread. The Desk
   Chat tab (P1.01 surface) lists threads; switching threads is instant (no run).
3. **Per-turn plan card + budgets (REQ-CHAT-10).** Every Assistant turn opens with the plan card:
   what it will do, tool budget, per-turn credit budget, tier, cancel; the three actions —
   Run as background research (spawns `research_burst`), Do the first step only, Edit the plan.
   Hitting a per-turn cap pauses the turn with the over-cap card (never silently proceeds).
   Preparatory tools return a run sheet — `start_workflow`/`propose_outline`/`visualize`/`elicit`/
   `measure` never create runs themselves (REQ-CHAT-6): they render the sheet and the user clicks
   Run (which lands in P1.06's sheet; the tool output here is the sheet payload).
4. **Typed `read_artifact` refs (REQ-CHAT-8).** `@v3 §II`, `@review:v2`, `@outline`,
   `@finding:v2/17`, `@claim:v2/41`, `@figure:<id>`, `@voice` resolve through a resolver over the
   artifact registry; unresolvable → tool error naming what was looked for; default scope is
   section-scoped; `--all`/whole-document reads show the token footprint before fetching.
5. **Attachments (REQ-CHAT, PRB.02 reuse).** PDF/DOCX/MD/TXT attachments route through the existing
   fetcher/convert pipeline (quarantine → convert → canonical Markdown) and land as chat source
   notes in the assistant research namespace — never as project corpus. Images are out (1.x).
6. **Turn cost strip + activity strip (REQ-CHAT-9/11).** The strip shows per-turn credits spent,
   searches/fetches used vs budget, and the workspace spend total — all from run events/metered
   rows, never parsed from model text. The model-tier picker is notch-only (Base/Balanced/Frontier;
   the thread default is Base).
7. **Compaction + pins (REQ-CHAT-12/13).** PreCompact writes `brief.md` ≤600 words (decisions,
   open questions, pinned facts); PostCompact re-injects it; "What the assistant remembers" opens
   the brief + pins read-only and corrections write through (a correction is itself a Guidance-class
   note). Pins cap at 12 with the token footprint shown.
8. **`research_burst` — authored skill + manifest.** Write `packages/protocols/skills/research_burst/`
   (Rhema-owned; declare it in `upstream-port.manifest.mjs` as Rhema-authored so the drift checker
   knows) and `packages/protocols/manifests/research_burst.ts`: plan (judge — decomposes the
   question into fetches) → fetch (research — ≤N sources, N from the plan card) → distill
   (generate — the research note + ≥1 source card). Estimator `15 + 5·sources +
   0.002·fetched_tokens` in `ESTIMATORS.research_burst`. Output is exactly one distilled research
   note + source cards (`agents/assistant/research/`); it never produces an outline, thesis pick,
   or originality verdict — assert by artifact-type whitelist. URL policy: the run inherits the
   seat's `UrlPolicy` (`allowlist`/`denylist`/`allowlist_plus`); every fetch rides the egress-proxy
   metered path with the run's cap; source-card failure → `[unverified]` note, not a retry storm.
9. **Two-conduit rule, enforced + tested (REQ-SPEC-15; §16.3 #7).** Assert at the mount-policy
   level: no Drafter/Editor run may mount `agents/assistant/**`; a chat turn's only paths into
   drafting are (a) an `outline` artifact via `outline-from-research` (P1.12) and (b) promoted
   Guidance. The conduit check runs as a contract test over `SEAT_TABLES` + the skill's declared
   output kinds — closing §16.3 #7's "verified, not just asserted" requirement in code.
10. **"Ask about this draft" (§7.4; REQ-CHAT-19 amended).** Passage selection / ⌘J opens the
    composer with the `@v3 ¶…` anchor; suggestions arrive as proposal cards (the P1.02 primitive,
    block provenance `assistant`, Accept = one transaction); suggestions are ≤1 paragraph —
    anything larger is refused with the pointer to `/lineedit @section` or `/revise` (both 1.x;
    the refusal copy must name them as commands, not imply they exist). Side questions asked while
    a run is live see only committed artifacts + the feed (REQ-CHAT-20) — assert the read path
    filters uncommitted run-projected state.
11. **Empty state + scratch path (§7.6; REQ-CHAT-29/30).** No project → the Page is a quiet
    placeholder, the Desk defaults to Chat with the four starter chips (Research a question ·
    I have a thesis · Interview me · Paste my notes) and exactly one next-step card on the
    Timeline. "Paste my notes" creates `agents/author/notes.md` via the Author seat's normal write
    path. REQ-CHAT-30's activation instrumentation (turn → run sheet → first gate events) lands
    here as event emission; the trial-pocket economics are P1.16's.

## Cross-cutting invariants — re-check before opening the PR

- Two-conduit rule (REQ-SPEC-15): chat is ephemeral; source notes are durable but assistant-scoped;
  nothing a chat produced mounts into a Drafter/Editor run.
- Fetcher discipline: all network goes through `apps/fetcher` (SSRF, ≤1 req/s/host, robots, honest
  UA); the convert step is no-network. The Assistant's fetches inherit the run's URL policy.
- Cost honesty: every strip/estimate number comes from metered rows/events, never model text.
- Canonical vocabulary: seat = Assistant; the harness is never named; "tokens" only under Advanced.
- See 00_MANIFEST.md § Cross-cutting invariants.
