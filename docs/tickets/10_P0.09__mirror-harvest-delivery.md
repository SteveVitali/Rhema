## Goal
The artifact pipeline between tables and files: materialize the per-seat mirror, harvest writes back
into content-addressed versions, run the delivery transaction with its validations (sidecars,
cited ⇒ fetched), and build the access report / boundary attestation from server-side facts.

## Load

## In scope — deliverables
1. **Materialize (REQ-DATA-5):** pure function of `(project_id, seat, persona_profile_id, run inputs,
   hydration.overlays[])` → tree with `.rhema/manifest.json` (path → artifact_version_id + sha256);
   per-seat mounts exactly the §12.6 tables (Drafter/Editor/Persona builder/Assistant/System;
   `preferences.md` mount point reserved, never in Editor/independence manifests — REQ-OBJ-10);
   `manifest.md` generated from tables (REQ-VIS-6); materialization before step 1 and at every
   resume, never mid-phase; read-only paths mounted read-only at the kernel (with P0.06's image).
2. **Harvest (REQ-DATA-6):** walk the seat's writable namespaces only; hash; version changed/new
   paths via the path→kind map (unknown paths default by directory or fail); record
   `producerQueryId`; identical files unversioned; read-only hash check vs the manifest — mismatch
   fails the step; write-back diff filtered by the seat's write allowlist, out-of-allowlist and
   immutable-path writes dropped + counted `boundary.violation` (§12.2).
3. **Delivery transaction (REQ-DATA-7 amended):** final harvest validates sidecars (P0.04 parsers),
   runs cited ⇒ fetched against the proxy fetch log (every `claim.url` **and** every
   `claim.sources[].url` — REQ-VIS-9/REQ-OBJ-18), runs the **model-independent verdict source
   check (§12.8(c); REQ-SPEC-25(c)):** a `verified`/`contradicted` Tier-1 verdict must cite a URL
   whose registrable domain matches the claim's own citation, is on the curated reputable-source
   list, or was reached from a search result (never only from a link inside a fetched page) —
   otherwise the verdict is downgraded to `unverifiable` with `sourceCheck: 'suspicious_source'`
   at commit (review 13 F40) — and runs producer checks (second read's `producerQueryId` = the
   orchestrator-launched scoped query — §12.2), then in one Postgres transaction: correspondence_item + rows + `immutable=true` + input-draft freeze + obligation
   spawn/join hook (the logic itself is P0.12; the transactional seam is here) + timeline event.
   Validation failure → `failed(validation)`, files retained as partial, nothing immutable; the
   ledger debit is a separate retried transaction (P0.11's op).
4. **Freeze semantics (REQ-DATA-21/24):** freeze on first run-read/dossier-ref/promote/export;
   `v(N+1) origin=human_revision` on editing a frozen head (API-level; UI later).
5. **Attestation (REQ-DATA-19/20; REQ-ARCH-16/20 amended; REQ-SPEC-10's reporting half):**
   `access_report` built from the hydration manifest + proxy request log + subagent launch records
   (+ in-container audit as secondary "attempts"); `boundary.attested` emitted at delivery;
   iteration caps as orchestrator budgets (audit ≤3, gap ≤3, re-plan ≤2 → `completed_partial`).
6. **Round-trip goldens (REQ-DATA-9 a/c):** materialize + harvest with no changes → zero new
   versions, on the three real projects. (The markdown↔ProseMirror halves (b)/(d) belong to the
   editor ticket P1.02.)

## Acceptance criteria
- [ ] Golden: materialize + immediate harvest on each of the three real projects yields zero new
      artifact versions (REQ-DATA-9a). *(deterministic)*
- [ ] Seat-mount tests: the Editor's tree contains no `agents/author/**`, no voice-print/lexicon/
      exemplars, no `preferences.md`; the second read's namespace exactly `[draft]` (with P0.06).
      *(deterministic)*
- [ ] A fixture dossier whose claim ledger cites one URL absent from the proxy fetch log →
      `failed(validation)`, artifacts partial, nothing immutable; same for a `sources[].url`
      (REQ-VIS-9 AC). *(deterministic)*
- [ ] `chmod +w` + edit of a read-only mirror file from the agent uid → harvest hash-check fails the
      step (review 13 F14). *(deterministic)*
- [ ] Out-of-allowlist write dropped and counted as `boundary.violation`; >5 violations or an
      immutable-artifact write quarantines the run's artifacts (§12.4 `boundary` class).
      *(deterministic)*
- [ ] Verdict source check: a fixture whose `contradicted` Tier-1 verdict cites only a domain
      reached from inside a fetched page is downgraded to `unverifiable` with
      `sourceCheck: 'suspicious_source'` at commit; a citation-matching domain passes (§12.8(c)).
      *(deterministic)*
- [ ] `access_report` fixture: mounted-paths counts from the manifest, fetch counts from the proxy
      log, subagent scoping listed, denied attempts as a secondary count; delivered dossier renders
      the attestation data (REQ-DATA-19). *(deterministic)*
- [ ] Delivery transaction atomicity: induced crash between row insert and freeze rolls back all of
      it; the retried ledger debit never rolls back a delivered dossier (REQ-DATA-7).
      *(deterministic)*
