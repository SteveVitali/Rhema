- **Sequence:** 6 of 50

## Goal
The sandbox side of the run model: the `Engine` abstraction and its `AgentSdkEngine`
implementation, the `apps/run-task` GKE image with `harness`/`agent` privilege separation
(REQ-SPEC-10), input-scoped subagent launching, the SDK→event mapper with recorded fixtures, and
`FakeEngine` for integration tests.

## Load
- Spec §12.2 (`Engine` interface; `AgentSdkEngine` `query()` options verbatim — cwd, baked skills,
  `agents` roster, hooks, `permissionMode: "dontAsk"`, cosmetic disallowedTools, `maxBudgetUsd`,
  `maxTurns`, scrubbed env, subagent depth 1, ≤5 concurrent, 1-h caching, OTel, GCS sessionStore,
  abortController), §12.4 step 4 (provisioning + uid split detail; the Unix-socket hook daemon),
  §12.5 (event catalogue + mapper rules), §12.6 (input-scoped subagent mechanics: private mount
  namespace, distinct uid, `tools:["Read"]`, no Bash; `producerQueryId`), REQ-ARCH-7/14/15,
  REQ-SPEC-10, ledger G15/G18/M11.

## In scope — deliverables
1. **`packages/engine`:** `Engine { startPhase(req): AsyncIterable<EngineEvent>; abort(reason); usage() }`;
   `AgentSdkEngine` per §12.2; a stub `ManagedAgentsEngine` passing the same conformance suite
   (REQ-ARCH-7); `FakeEngine` replaying recorded fixtures (ledger G21) for P0.15's integration suite.
2. **`apps/run-task` image** (arm64/amd64, distroless, SDK vendored; 1 vCPU/2 GiB baseline; runs as a
   GKE Job pod): starts as uid
   `harness` (receives `RUN_TOKEN`, `API_INTERNAL_URL`, proxy credential via a file only `harness`
   reads), launches the SDK process as uid `agent` with the scrubbed env (`RUN_ID`,
   `ANTHROPIC_BASE_URL=proxy`, `CLAUDE_CODE_DISABLE_AUTO_MEMORY=1`, per-run `CLAUDE_CONFIG_DIR`,
   nothing else); hooks/heartbeat/commit/audit run as `harness` via the local Unix-socket daemon the
   `agent` uid cannot read; root filesystem read-only, writable tmpfs only for the seat's writable
   namespaces (mount mechanics per §11.5; the materialization *content* comes from P0.09).
3. **Input-scoped subagents** (REQ-DATA-17/18; REQ-ARCH-19 amended): orchestrator-launched separate
   `query()` calls in a private mount namespace (`unshare -m` + tmpfs binds) under a distinct uid
   with exactly the enumerated files and `tools: ["Read"]`; drafting never fans out; the scoped
   query id recorded as `producerQueryId` on what it writes.
4. **Event mapper** (`packages/engine/mapper/`): SDK messages → the §12.5 typed events; conformance
   suite with recorded fixtures; `agent.note` only from `packages/contracts/notes.ts` templates
   (REQ-ARCH-14); `source.read` URLs from tool results, never model requests (REQ-ARCH-15);
   whitelist validation; internal vs user visibility split; per-phase `usage.tick` emission.
5. **OTel** config with all content flags off (§13.5).

## Acceptance criteria
- [ ] Privilege-separation test in the built image: a process under uid `agent` cannot read the
      token/credential file or the hook daemon's socket credentials; `env` of the SDK process
      contains only the scrubbed set (REQ-SPEC-10). *(deterministic)*
- [ ] A shell escape simulation (`node -e` HTTP call from uid `agent`) reaches neither the internal
      API (no token) nor the provider (proxy refuses credential-less requests — asserted against a
      stub proxy). *(deterministic)*
- [ ] Mapper conformance suite green on recorded fixtures; CI asserts no internal event type is
      emitted as `user` (REQ-ARCH-12's mapper half); a fixture with hostile fetched-page text never
      reaches an `agent.note` (REQ-ARCH-14). *(deterministic)*
- [ ] Input-scoped subagent test: the scoped query's mount namespace contains exactly the enumerated
      files; a Read outside them fails at the kernel, not just the hook (review 13 F13).
      *(deterministic)*
- [ ] `ManagedAgentsEngine` stub and `AgentSdkEngine` both pass the event-mapper conformance suite
      (REQ-ARCH-7). *(deterministic)*
- [ ] One live phase (`editorial-review` phase 0 on a fixture) runs end-to-end through
      `AgentSdkEngine` in dev, producing the piece brief and a valid `phase-result.json`. *(agentic)*
