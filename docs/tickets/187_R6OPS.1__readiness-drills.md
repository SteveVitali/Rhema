## In scope — deliverables
1. **(a) Restore drill:**
   - PITR to a scratch instance at a recorded timestamp; verify row counts and one tenant read;
     destroy the instance;
   - record the RTO and the restore point;
   - script it under `scripts/live/restore-drill.mjs`.
2. **(b) Rollback drill:** on a preview, deploy N, revert to N−1, verify the markers and
   provenance; teardown verified.
3. **(c) Egress-denied playbook drill:** run the playbook end to end on the canary; record the
   timeline.
4. **(d) Alert delivery:** each alert policy proven to page the real sink (a synthetic trigger per
   policy, or a documented test-notification path); record the receipt times.
5. **(e) On-call/incident runbook:** names the operator as responder and the paging path
   (`docs/ops/on-call.md`).

## Out of scope
- HA changes (R6INF.1); any lasting prod data change.
