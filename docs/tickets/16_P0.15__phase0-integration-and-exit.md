## In scope — deliverables
1. **FakeEngine integration suite** in CI (ledger G21): recorded-fixture runs exercising gates,
   orphan resume, cancel, cap exhaustion, stale-task fencing against real `api` + `worker` and a
   preview Aurora.
2. **Live end-to-end runs in `dev`:** a Review of each of the three real projects; a Revise
   answering one of them (exercising Approve triage + overlay write-back + obligations); a
   Fact-check; a Quick Voice build. Boundary attestation `violations = 0` derived from the
   hydration manifest and proxy log; every sidecar `parseStatus = ok`; cited ⇒ fetched green
   against the proxy log.
3. **Instrumented cost runs (§16.3 #1):** one proxy-metered run per ported workflow × rigor notch
   (within a stated budget); replace the provisional estimator constants and §6.1 rigor multipliers
   with measured values (as versioned estimator data); record the phase-aware cache economics
   (review 13 F8); proxy-metered = SDK-reported ± 2% per run (§12.7).
4. **Nightly golden runner:** the three projects (+ protocol fixtures as they exist) as private
   `evals/fixtures/` with deterministic scorers (§13.5 list); green-dossier→parser-fixture growth
   hook (P0.04) wired; nightly score floors block protocol/engine promotion (REQ-ARCH-36).
5. **§18 pilot wave** on the dev set (REQ-EVAL-5, REQ-EVAL-17): all six arms executable,
   normalization + matching exercised with trained matchers, deterministic scorers green, σ_d
   estimated, benchmark n fixed and recorded.
6. **Exit readout:** a written document quoting each §17 Phase-0 exit criterion with its measured
   result, plus first measurements of start-latency p95 (informs the warm-pool/G19 decision) —
   the input to milestone gate G1.
