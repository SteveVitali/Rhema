## Goal

BL-97 / REQ-WRITE-3 (RV-31): a `/` trigger in the editor opens a small command menu that
inserts the document's block-level constructs (headings, lists, quote/code blocks, figures
— whatever the editor's node set already supports). **Design constraint:** this is not a
Notion clone — the menu lists only constructs the schema actually has, opens on `/` at a
block start, navigates by arrow keys + Enter, dismisses on Escape, and is fully
keyboard-first. Mouse hover works; nothing else is required.

## Spec §§ / anchors

- `packages/editor` owns the editor logic (`format-commands.ts` + tests show the command
  shape); the SPA's editor integration lives under `apps/web/src/spa/` (`editor*.tsx` and
  the mount). Read `packages/editor`'s scoped AGENTS.md-equivalent + `apps/web/AGENTS.md`.
- Follow the existing keymap/command conventions (chord literals, `format-commands`);
  declare new `data-*` selectors in `dom-contract.ts`.
- Private protocol text must not leak into any browser bundle (`check:protocol-markers`).

## Acceptance (deterministic)

- Unit/DOM tests: `/` at block start opens the menu (data-hook), filters by typed text,
  arrow+Enter inserts the chosen node at the caret, Escape dismisses, no menu inside a
  code block (or wherever the schema forbids), and the typed `/` is consumed on insert.
- `pnpm turbo build lint typecheck` + editor + web suites + `check:dom-contract`/`spa-budget`/`spa-env`/`protocol-markers` green.
- Preview walk: editor screenshot with the menu open.

## Out of scope

- Command palette (`Cmd-K`), formatting toolbar, AI-authored menu entries, mobile keyboard
  handling, REQ ids other than WRITE-3.
