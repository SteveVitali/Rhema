## Goal

The 2026-11-26 prod error sweep (R6FIX.54's post-fix verification) found a 12-hit burst of
`unhandled_route_error` on `GET /internal/runs/:id/research-budget` spanning 11-24T17:05Z →
11-25T03:43Z (quiescent since; correlates with funded-window run activity — the run-task's
retry gate consults this route before re-executing a research phase). The error is a pg
`DatabaseError` (`errorClass:"error"`, name `'error'`) thrown inside `withTenant` →
`PgPoolTxRunner.run` → `readRunWebToolsPolicy` — but the logged line carries **no SQLSTATE**:
`stackForLog` strips the message (by design — messages can embed user text) and the route
line emits only `errorClass` + frames, so the failure class is undiagnosable from logs.

Two arms:

- **Observability:** the bounded driver-tag mechanism already exists (`ERROR_TAG_FIELDS` —
  `code`/`constraint`/`routine`/`syscall`, enum tokens never messages) but the route error
  line never carries it. `driverTagsForLog(err)` + a `driverTags` field on
  `RouteErrorFields`, emitted by `formatRouteErrorLine` after re-validating the token
  alphabet at the seam (ADR-053's inert-only contract holds against direct callers). A pg
  `DatabaseError`'s SQLSTATE then lands on every `unhandled_route_error` line.
- **Resilience:** `researchBudgetState`'s two tenant reads (`readRunWebToolsPolicy` +
  `researchBudgetConsult`) are pure SELECTs — one guided retry on transient classes absorbs
  the connection-drop signature. `isTransientDbReadError`: SQLSTATE `08xxx` (connection
  exception class), `57P01` (admin shutdown), `40001`/`40P01`, node `ECONNRESET`/`ETIMEDOUT`/
  `EPIPE`. The run-task's consult already degrades to `null` on non-2xx — this shrinks how
  often it must.

## Acceptance (deterministic)

- `isTransientDbReadError` legs: `08003`/`57P01`/`ECONNRESET` true; `23505`/no-code/
  non-object false.
- Retry legs: one transient failure → consult returns (2 tx attempts); non-transient →
  propagates no retry; transient twice → propagates (one retry, never a loop).
- `driverTagsForLog` + emit legs: pg-shaped error → `code=08006 routine=exec_query`; absent
  → field dropped; hostile value → dropped at the emit seam.
- `turbo build` + typecheck + lint green on the three touched packages.
