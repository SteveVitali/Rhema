## In scope — Stage A (code + tests, $0)
1. **The full format set.** Extend `EXPORT_FORMATS`/`EXPORT_FORMAT_INFO` to `md, txt, html, docx,
   rtf, pdf, latex`; pandoc produces html/rtf/latex (docx unchanged); **pdf goes through Typst**
   inside the same isolated container (new binary dep — licence check per `check:licenses`).
   **Substack-flavoured md is a *profile* of the md export**, not an eighth format — a
   `profile: 'substack'` option on `md` (§13.4; record the choice in the registry). The
   container rejects anything outside the registered set before work begins, as today.
2. **`--citeproc` CSL rendering** (epic row 49): five CSL styles at MVP (pick the conventional
   five — e.g. APA, MLA, Chicago author-date, Harvard, Vancouver — and record the choice in the
   run ledger); rendered from the project's CSL-JSON items + cite nodes (P1.02's schema); the
   style is an export-dialog option; 10 styles is 1.x.
3. **Footnote + figure fidelity per format:** footnotes → real docx/LaTeX footnotes (docx already
   green at beta — extend the golden to latex/html/rtf); figures per the REQ-VIZ-15 matrix —
   **SVG for HTML/PDF/LaTeX; PNG@2x for docx/rtf; native tables everywhere; `.txt` keeps alt +
   caption + source; `alt` maps to the format's alt field; the source line exports as a footnote
   where footnotes exist; `[unverified data]` becomes a caption note until resolved; the `.md`
   export carries spec + data + provenance so the figure is reproducible outside Rhema; dark
   renders never export.**
4. **The block-level provenance appendix** (REQ-POS-7): generated from the run's `provenance_map`
   (capture accrues from PRB.07/P1.02 — a human edit inside a recorded span degrades the block to
   `mixed`; REQ-POS-9 is write-only machinery already); **off by default, one toggle in the export
   dialog, granularity labeled honestly** ("block-level — blocks edited by the author after
   drafting are marked *mixed*"); appendix-capable formats only (html/pdf/docx/latex/md — `txt`
   omits it); never promised above block-level (REQ-POS-10 keeps span-granular export 1.x).
5. **Disclosure surfaces** (REQ-GENRE-5's export half + REQ-POS-6 consumption): the export dialog
   gains the protocol-conditional attachments — **Academic** → the ICMJE-shaped disclosure
   statement generated from run history (the template registers with P1.21; the dialog surface +
   generator hook land here and degrade to the general template until then — a service, never a
   gate); **Op-ed** → the exclusivity reminder line in the dialog; the AI-use statement attach
   toggle (PRB.11's) is unchanged.
6. **The whole-account export zip** (REQ-ACCT-3): a worker job builds the zip — every project in
   its on-disk layout (`manifest.md`, `drafts/`, `correspondence/`, `agents/author/*`; the
   `agents/editor/*` tree excluded — the user is the author), every voice (`PERSONA.md`, `docs/`,
   `profile/` incl. the calibration report), samples as canonical markdown, a ledger CSV, and the
   preference-profile rows when they exist (§11.7: the profile exports with the account). The zip
   is delivered as an **emailed link with a 7-day expiry** (§14.7's *Export everything* — the
   Settings trigger is P1.20's; this ticket owns the build + delivery + expiry machinery and an
   API route P1.20 calls).
7. **The fresh-account importer + golden round-trip:** importing the zip into a fresh account
   reproduces every project and voice (REQ-ACCT-3 — golden-tested on the three real projects);
   importer is idempotent (re-import of the same zip is a no-op, not a duplicate).
8. **Isolation + discipline:** pandoc/Typst run only in `apps/export` — never in api/web images
   (PRB.11's AC stands); the export dialog still shows the open-obligation count with links and
   never blocks (§11.7); the `pre_export` deferred-obligation surfacing (PRB.11) is unchanged.
9. Deterministic verification: `turbo build lint typecheck` + `pnpm test` green; per-format golden
   fixtures on the seeded project; the zip round-trip golden.
