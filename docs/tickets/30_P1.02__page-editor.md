## Goal

The Page becomes the real editor: a Tiptap/ProseMirror WYSIWYG whose document model **is** the
Rhema Markdown profile — schema first, markdown as its canonical serialization — mounted in the
P1.01 pane layout at `/p/:project/v/:n` and `/p/:project/v/working`. It carries the editing
rules the beta's CodeMirror stopgap only approximated: findings as sidecar decorations, the
proposal card for agent-origin changes, block-level provenance with write-only span capture,
and read-only-during-runs enforcement.

## In scope — Stage A (code + tests, PR-able)

1. **The schema-first profile.** A ProseMirror schema for the Rhema Markdown profile
   (ledger H9): the CommonMark/GFM block+inline set the skills emit, footnote nodes (`[^n]`),
   inline and block math, `[@key]` cite nodes over CSL-JSON bibliography items, and a figure
   block node (the §7.5 payload lands in P1.13 — the *node* ships now so the schema is closed
   for MVP). Write the parser (`md → PM`) and the serializer (`PM → md`) such that markdown is
   the canonical serialization — the stored artifact bytes are markdown, never PM JSON.
2. **REQ-DATA-9 (b)/(c) golden suite — closes the rest of D-P0.09-2.** `md→PM→md` byte-stable
   on already-canonical text; `PM→md→PM` structural equality; fixtures include the three real
   projects' canonical drafts and convert-pipeline output (post-normalize — the (d) boundary).
   Imported-arbitrary-markdown byte-stability is explicitly not claimed.
3. **Block-id sidecar.** Each version stores `{blockId → (ordinal, contentHash)}` beside the
   markdown — never as comments or attributes in the text. Stripped at materialization together
   with the provenance map; re-derived on load by hash + ordinal with a small fuzzy step for
   edited blocks; exports, diffs and the skills' mirror never see ids (review 13 F23). This is
   the substrate REQ-MOBILE-6's block patches (M17, P1.03 schema) and finding anchors stand on.
4. **The Tiptap Page.** Write view = WYSIWYG over the schema; Read view = the typeset/print
   rendering (the existing `@rhema/markdown-view` skeleton fills in here or stays a server
   render — pick the cheaper correct seam). The Page renders *any* artifact, read-only for
   non-draft kinds; `/v/working` is the editable head. Figure blocks render their cached SVG
   or a placeholder; citation nodes resolve `[@key]` against the project's CSL-JSON items.
5. **Bibliography + citation import (matrix row 37).** CSL-JSON items as project artifacts;
   importers for BibTeX, CSL-JSON and Zotero-export formats into that item set; `[@key]` cite
   nodes reference them; unresolvable keys render visibly (never silently dropped).
6. **Findings as sidecar decorations — never marks.** A decoration layer projects
   `Finding[]` anchors onto the live doc via findings-core's resolution ladder; the stored
   markdown stays byte-clean and reviewed drafts stay immutable. The Margin surface and its
   styling catalogue are P1.07 — this ticket lands the decoration mechanism + a minimal card
   affordance the shell can show.
7. **The proposal card (REQ-IDE-45 amended; REQ-DATA-28 amended; REQ-CHAT-19).** Agent-origin
   in-place changes (Assistant suggestions ≤1 paragraph, Figure inserts, Apply replacements)
   arrive as a card beside the Page: anchored to its span, accept applies **one plain
   ProseMirror transaction** with origin `agent:<seat>:<run>`, reject dismisses. Agent-origin
   transactions are **excluded from the human's undo stack** — `⌘Z`/`⌘⇧Z` walk the user's own
   edits only (§5.12). No suggestion marks anywhere (1.x).
8. **Provenance capture (REQ-DATA-29 amended; REQ-POS-8/9).** Block-level provenance recorded
   from transaction origins (`human` / `human-mobile` / `drafter:run` / `pasted` / `assistant`
   / `suggestion_applied`) into the `provenance_map` emitted at materialization and stripped
   from harness-facing markdown. **Span-granularity capture at agent-origin transactions** —
   write-only: record the span set per agent transaction; any human edit inside a recorded
   span degrades that block to `mixed`; no span rebasing. The **block-level Authorship
   overlay**: a View-menu (Advanced) toggle rendering provenance as sidecar decorations —
   read-only, never stored in the markdown. Span-level marks/overlay/rendering are 1.x
   (REQ-POS-10 — not here).
9. **Status-bar meters (REQ-PROD-14).** Word count, reading time, and the venue-cap meter from
   the protocol's `length_norms` + venue row ("+212 over WaPo") in the P1.01 status bar.
   Over-cap shows the plain "+N over" meter — the *Cut to length* chip is 1.x.
10. **Editing rules (REQ-IDE-44 amended; REQ-DATA-24's surface).** Unreviewed draft → edit in
    place. Reviewed/frozen draft → typing forks `v(N+1) origin=human_revision` without a
    confirm, with the "Editing v(N+1) · findings from vN follow your text" banner and findings
    **projected** onto the new head (reuse the api's projection path — `editor-routes.ts`
    already resolves this for the beta editor; `Finding.projections[]`, lost anchors →
    *Whole piece* "passage changed — still applies?"). **During a run** that froze the head,
    the Page is read-only with the banner "Review in progress on vN — comments here become
    guidance for the next run · Cancel run to edit"; comments write `Guidance` rows. Never
    two writers of one draft — the runtime enforces, not just the UI.
11. **Persistence seam — do not fork it.** Until P1.03 lands the Yjs/Hocuspocus transport, the
    Page autosaves through the existing `editor-routes` save path (the debounce contract from
    `sync-machine.ts`: no Save button, no unsaved dialog, `⌘S` marks a restore point once
    P1.03 exists). Write the save seam as an interface (`EditorTransport` or similar) so P1.03
    is a transport swap, not an editor rewrite.
12. **Cutover.** `/p/:project` opens the Page on the working head. The PRB.07 CodeMirror route
    (`/p/:project/edit/:draftId`) is superseded — redirect it to the Page (keep
    `source-editor.tsx` + `public/editor.js` dormant for the 1.x Source mode; REQ-BETA-21's
    stopgap budget is now spent — the stopgap is *replaced*, not extended).
13. `turbo build lint typecheck` + `pnpm test` green; `check:licenses` (Tiptap/ProseMirror are
    MIT — verify new deps against the allowlist); `check:protocol-markers` clean — the client
    bundle must carry no protocol/eval text (REQ-ARCH-33).

## Acceptance criteria

- [ ] `md→PM→md` byte-stable and `PM→md→PM` structurally equal on the golden fixtures (the
      three seeded projects + converted samples); **D-P0.09-2 → DONE** with the suite named as
      evidence. *(deterministic)*
- [ ] Block ids live only in the sidecar map; a hash+ordinal+fuzzy re-derivation test covers an
      edited-block case; no id survives into serialized markdown, exports, or a materialized
      mirror. *(deterministic)*
- [ ] A finding renders as a decoration and the underlying markdown is byte-identical.
      *(deterministic)*
- [ ] A proposal accept applies a transaction with `agent:*` origin that `⌘Z` cannot undo;
      reject leaves the doc untouched. *(deterministic)*
- [ ] Provenance: origins recorded per block; an agent-span capture degrades to `mixed` on
      human edit inside the span; the Authorship overlay toggles read-only decorations and the
      markdown never changes. *(deterministic)*
- [ ] Footnote, math, and `[@key]` cite nodes round-trip; a BibTeX and a CSL-JSON fixture
      import into project items; a dangling key renders visibly. *(deterministic)*
- [ ] Typing on a frozen draft forks `v(N+1) human_revision` with the banner and projected
      findings; during a run the Page is read-only and comments land as `Guidance`.
      *(deterministic)*
- [ ] Status bar renders word count, reading time, and the venue-cap meter. *(deterministic)*
- [ ] Stage B evidence in the run ledger; no new OPEN deferral without a `D-P1.02-*` id.
      *(operator-gated)*
