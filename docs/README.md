## Operate a deployment

The [Pulumi guide](../infra/pulumi/README.md) and [production runbook](../infra/PROD-BRINGUP.md)
are for operators with the required infrastructure access. They are separate from the local
contributor setup. Start incidents at [on-call](ops/on-call.md); use the
[journey guide](../packages/journeys/README.md) for deployed acceptance and its spending controls.
Security assessment material lives under [security/](security/); it does not grant permission to test
the hosted service.

## Understand decisions and history

- [Architecture decisions](adr/README.md) explain why the system takes its current shape.
- The [ticket manifest](tickets/00_MANIFEST.md) defines the managed build chain. The
  [deferrals ledger](tickets/DEFERRALS.md) records verification still owed.
- [Build memory](build/README.md) holds the machine state, run records, and gate readouts. Its
  [ledger](build/LEDGER.md) distinguishes implementation progress from deployment evidence.
- Specifications and research below preserve the design record. Later amendments and ADRs can
  supersede statements in their original bodies. Their filenames and historical claims are retained
  so citations remain traceable.

Do not infer current production behavior from a source build, an old run report, or a dated price.
A live claim requires current deployment provenance and the relevant observed result.

## Document modes

The mode determines how a document may change. Most files in this directory are historical records,
not onboarding material. The index itself is living documentation.

| Mode                       | What it means                                                          | How it changes                                                      |
| -------------------------- | ---------------------------------------------------------------------- | ------------------------------------------------------------------- |
| **living**                 | maintained guidance or procedure                                       | verify against source and correct in place; preserve dated evidence |
| **frozen**                 | written once, then immutable (captured evidence / a ratified artifact) | not edited; corrections are recorded elsewhere                      |
| **frozen-with-amendments** | the ratified spec                                                      | amend via the manifest amendment protocol + an ADR; ids append-only |
| **append-only**            | a register or immutable-decision record                                | add rows/records; never rewrite a landed entry                      |
| **historical record**      | a committed record of what happened during the build                   | not rewritten; only broken references repaired                      |
| **generated**              | derived from source by a script                                        | edit the source + regenerate; never hand-edit the output            |
